# 系统说明与核验清单

## 每月核验

- [ ] 所有正式笔记都有合法 YAML、标题、日期和 `record_type`。
- [ ] 文献、政策、同行材料有可追溯来源。
- [ ] AI 摘要标明工具、输入范围和人工核验状态。
- [ ] 真实数据有数据规划、数据集登记、版本和处理日志。
- [ ] 学生与班级数据已匿名化，没有直接身份信息。
- [ ] 结论能追溯到原始数据、分析过程和反例。
- [ ] 教科研材料分解批次已保留文件、页码/章节、数据资产和证据位置。
- [ ] 教学材料已区分设计数据、预期数据和课堂真实数据。
- [ ] 学生交流数据已匿名化，并区分原话、概述和解释。
- [ ] 每批材料有独立复核记录，高严重度问题已经关闭。
- [ ] 十层级原始参照仍保留在库中，工作流和复核记录能够访问。
- [ ] 参考文献已查重，元数据、全文、阅读、核验和引用状态明确。
- [ ] 双链没有无意义断链，JSON 和 Base 文件可解析。
- [ ] 过期、重复和无权保存的资料已归档或删除。
