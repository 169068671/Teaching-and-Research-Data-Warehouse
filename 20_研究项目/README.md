# 研究项目总览

一个研究项目对应一个明确问题和一条完整证据链。新项目使用 [[../90_模板/研究项目模板]]。

## 每个项目必须连接

1. 一个或多个 [[../30_研究资料/02_研究主题/README|研究主题]]。
2. 一份 [[../90_模板/真实数据规划模板|真实数据规划]]。
3. 已登记的真实数据集。
4. 分析备忘与反例。
5. 主张—证据—解释链。
6. 最终成果与教学改进动作。
