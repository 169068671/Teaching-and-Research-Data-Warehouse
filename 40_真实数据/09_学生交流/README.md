# 学生交流数据

用于记录与教学和研究有关的师生交流，包括课堂问答、个别辅导、作品反馈、小组指导、课后交流、正式访谈和必要的线上沟通。

> [!danger] 隐私底线
> 只使用学生或小组匿名代码；不得记录姓名、学号、联系方式、家庭住址、私人账号等直接身份信息。涉及心理危机、家庭矛盾、健康、处分等高敏感事项时，不在一般教科研仓库保存细节，应按学校制度转交有权限的人员处理。

## 交流类型

| 类型 | 示例 | 主要价值 |
|---|---|---|
| 课堂问答 | 学生提问、解释、质疑和回答 | 概念理解、错误类型、思维过程 |
| 个别辅导 | 学习困难、作品修改指导 | 个体困难、支架措施、变化过程 |
| 作品反馈 | 对草图、CAD、原型、报告的交流 | 设计依据、反馈采纳、迭代证据 |
| 小组指导 | 分工、冲突、方案决策、进度讨论 | 协作、工程决策、项目管理 |
| 课后交流 | 学习体会、困难、兴趣和建议 | 学生体验、课程改进线索 |
| 正式访谈 | 按提纲开展并获得必要同意 | 研究问题的质性证据 |
| 线上沟通 | 教学平台或合规渠道中的必要交流 | 任务理解、反馈和持续支持 |

## 记录原则

1. 区分学生原话、教师概述和教师解释。
2. 只记录与教学改进或研究问题有关的最小必要信息。
3. 记录交流场景、发起者、主题、教师回应和后续行动。
4. 正式访谈应登记同意状态；日常交流转作研究数据时也要符合学校要求。
5. 不根据一句话给学生贴能力、性格或心理标签。
6. 需要引用学生原话时去标识化，并保留准确性核验方式。
7. 原始聊天截图、录音和转写文件按限制级数据管理，未经授权不得上传外部 AI。
