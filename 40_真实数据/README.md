# 真实数据总览

> [!important] 真实性底线
> 真实数据必须来自可说明的教学或研究现场。缺失可以保留为空，但不得由 AI 或人工“补成看起来合理的数据”。

## 数据分区

| 分类 | 典型内容 |
|---|---|
| `01_数据规划` | 研究问题—证据—指标—采集工具—频率—责任人 |
| `02_数据集登记` | 每份数据集的来源、范围、字段、版本、质量、权限 |
| `03_量化数据` | 成绩、量规评分、频次、时长、问卷量表、测试读数 |
| `04_质性数据` | 访谈转写、观察记录、开放回答、教师日志 |
| `05_学生作品与工程过程` | 草图、CAD、原型、测试、迭代、设计报告 |
| `06_课堂观察` | 学生活动、教师行为、课堂事件和时间线 |
| `07_问卷访谈` | 工具版本、发放、回收、样本、原始回应 |
| `08_数据质量与伦理` | 匿名化、知情同意、缺失异常、权限、版本和销毁 |

## 研究问题与数据匹配

| 想回答的问题 | 至少需要的数据 | 推荐补充数据 |
|---|---|---|
| 学生是否进步？ | 前后测或同一量规的多次测量 | 作品版本、访谈、课堂观察 |
| 某教学策略是否有效？ | 干预记录、结果指标、基线或对照 | 实施忠实度、学生体验、替代解释 |
| 学生如何完成工程设计？ | 过程性作品、观察、设计日志 | 屏幕录制、访谈、版本差异 |
| 为什么某环节困难？ | 错误样本、观察、学生解释 | 教师反思、任务分析、同行意见 |
| 成果能否迁移？ | 新情境任务和表现性评价 | 延迟测量、不同班级复现 |

## 数据文件原则

1. 原始文件只读保存，不覆盖。
2. 处理后的文件另存版本，并记录处理步骤。
3. 学生信息采用匿名代码，身份对应表不放入本仓库。
4. 每份数据集都建立 [[../90_模板/数据集登记模板|数据集登记笔记]]。
5. 每项采集活动先确认必要性、伦理与保存期限。
