# 教科研材料数据化分解复核对照材料

> [!important] 用途
> 本材料是数据化分解完成后的独立复核基准。复核者必须回到原始文件检查，不得只阅读 AI 摘要或分解报告。

原始十层级参照文本永久保存在 [[../30_研究资料/08_材料分解/教科研材料数据化分解十层级原始参照]]；本页是在原始参照基础上形成的执行检查表。

## 复核状态词

- `通过`：内容完整且能回到原始材料复核。
- `部分通过`：基本正确，但存在遗漏、定位不足或表达不严谨。
- `不通过`：与原文不符、证据不足、混淆事实与推断或存在编造。
- `不适用`：材料类型确实不涉及该项，并说明理由。
- `待补材料`：作者声称存在，但当前批次未获得原件或附件。

## 一、基础信息

### 应有内容

- 题目、作者、机构、年份、来源。
- 文章、硕博论文、课题申报书、结题材料、教学材料等类型。
- 研究方向、学段、学科和研究对象。

### 复核问题

- [ ] 标题、作者、年份、机构与原件一致。
- [ ] DOI、网址、文号、学位授予单位等稳定标识已核验。
- [ ] 材料类型、版本和主文件判断正确。
- [ ] 研究方向、学段、学科和对象有原文依据或被标为分析者分类。

## 二、研究逻辑

### 应有内容

- 研究背景与现实问题。
- 核心研究问题、研究目标与假设。
- 核心概念、操作性定义和理论依据。
- 研究对象、场景、周期和样本。

### 复核问题

- [ ] 作者明确陈述与分析者推断已经分开。
- [ ] 研究问题、目标和假设没有相互混淆。
- [ ] 核心概念的操作性定义有准确位置；未定义时已标记缺失。
- [ ] 对象、样本、周期和场景与原文一致。

## 三、数据清单

### 应检查的数据

- 学生成绩、前后测、问卷和量表。
- 课堂观察、访谈、教师日志和学生交流。
- 学生草图、CAD、模型、原型和设计报告。
- 测试数据、失败记录、迭代次数。
- 课堂录像、录音、图片。
- 同伴互评、小组分工和学习过程记录。
- 政策、文献、同行案例等外部数据。

### 复核问题

- [ ] 材料实际呈现的数据没有遗漏。
- [ ] “实际呈现、作者声称存在、研究设计应有”三种状态已区分。
- [ ] 教学设计中的预期产物没有被误当成真实课堂数据。
- [ ] 数据名称、数量、格式和位置能够复核。

## 四、数据来源与产生过程

### 每类数据应追踪

- 谁产生、何时采集、在哪种教学情境下采集。
- 使用什么工具或量规、样本量是多少。
- 原始文件在哪里，是否经过清洗、编码或筛选。
- 是否匿名化，是否能够复核。

### 复核问题

- [ ] 数据来源、产生者、时间和场景有证据。
- [ ] 工具、样本、字段、单位和采集频率准确。
- [ ] 原始数据与处理后数据没有混淆。
- [ ] 匿名化、权限和敏感级别合理。

## 五、变量与指标

### 技术与工程示例

- 问题定义能力与约束条件识别。
- 方案生成数量、差异和决策依据。
- 原型测试次数、失败原因和迭代优化幅度。
- 成本、性能、可持续性权衡。
- 团队协作与工程表达。

### 复核问题

- [ ] 抽象概念已转换成可观察指标或明确标记无法测量。
- [ ] 自变量、因变量、控制变量和背景变量没有错置。
- [ ] 指标单位、量尺、允许值和评分规则完整。
- [ ] 指标解释没有超出测量工具实际能够测量的范围。

## 六、研究方法审计

### 应判断

- 研究问题需要什么数据，作者实际用了什么数据。
- 分析方法是否合适，数据是否足以支持结论。
- 是相关关系还是因果关系。
- 是否存在样本偏差、测量偏差或选择性报告。

### 复核问题

- [ ] 研究问题、数据和分析方法相互匹配。
- [ ] 样本和分组能够支持相应强度的结论。
- [ ] 信度、效度、评分者一致性和编码过程如实记录。
- [ ] 相关、差异、预测和因果表述没有混淆。

## 七、主张—证据链

### 标准结构

| 研究主张 | 使用的数据 | 分析方法 | 证据位置 | 支持程度 | 反例或限制 |
|---|---|---|---|---|---|
| | | | | 强/中/弱/不支持 | |

### 复核问题

- [ ] 每条核心主张都链接到具体数据和分析过程。
- [ ] 证据位置能够定位到文件、页码、表号、图号或附录。
- [ ] 支持程度与证据强度相符。
- [ ] 作者解释没有被提升为已经证实的事实。

## 八、数据缺口

### 重点检查

- 声称使用但没有呈现的数据。
- 只有结果数据、缺少过程数据。
- 缺少基线、对照、复测或三角互证。
- 缺少量表、访谈提纲、观察表、评分标准或编码规则。
- 结论超出样本和研究范围。

### 复核问题

- [ ] 关键缺口没有被遗漏或用推测补齐。
- [ ] 缺口对结论的影响已经说明。
- [ ] 能否补充及需要补充什么材料已经列出。

## 九、可复用价值

### 应判断

- 可借鉴的研究问题、评价指标和课堂观察工具。
- 可扩展的真实数据规划和可验证假设。
- 与高中技术与工程学科的连接点。
- 可形成新课题或论文的研究空白。

### 复核问题

- [ ] 已分为“可直接借鉴、需修改、不可使用”。
- [ ] 迁移到自己课堂的适用条件和风险明确。
- [ ] 明确指出需要重新采集的真实数据。
- [ ] 没有把他人数据当作自己的数据使用。

## 十、入库结果

### 标准产物

- 来源总笔记、研究方向与研究主题。
- 参考文献笔记和人工核验后的 AI 摘要。
- 数据资产清单、变量指标字典、方法审计。
- 主张—证据链、数据缺口、可复用研究设计。
- 政策、同行研究、教学材料和学科概念双链。
- 每个源文件各自对应的参考文献引用内容明细；无引用的源文件也必须有零引用说明。

### 复核问题

- [ ] 所有正式产物已进入正确分类。
- [ ] 原始材料、批次报告和分拆笔记相互链接。
- [ ] `record_type`、来源、状态、敏感级别和核验状态完整。
- [ ] 没有无意义断链、重复笔记或未处理的版本冲突。
- [ ] 引用内容明细数量与源文件数量一致，且不能用批次汇总代替逐文件明细。
- [ ] 每份明细均列出引用方写的话；未检出引用时明确记录0条参考文献、0处引用事件和检查范围。
- [ ] 可能直接引语、二手引用候选、疑似错引和被引原文核验状态已如实标记。

## 一票否决项

出现以下任一情况，整批不得标记完成：

- 编造数据、参考文献、引文、页码、政策条款或统计结果。
- 无法区分原文事实、作者观点、分析者推断和 AI 输出。
- 核心结论找不到原始证据位置。
- 未经授权保存或处理可直接识别学生的信息。
- 教案预设、范例作品或作者声称存在的数据被当成真实实施数据。
- 任意一个源文件缺少独立的参考文献引用内容明细，包括未检出引用但没有生成零引用说明的文件。

## 使用方式

每批材料完成初次分解后，复制 [[../90_模板/教科研材料数据化复核记录模板]]，由人工或独立第二遍 AI 会话逐项填写差异和修正记录。
