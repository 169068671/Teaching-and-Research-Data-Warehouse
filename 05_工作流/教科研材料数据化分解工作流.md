# 教科研材料数据化分解工作流

> [!important] 工作流目标
> 把文章、硕博论文或完整课题资料拆成可追溯的数据资产、研究逻辑、主张—证据链、数据缺口和可复用研究设计，并用独立复核对照材料检查，而不是只生成摘要。

## 一句话调用

把材料放入 [[../00_Inbox/待分解材料/README|待分解材料]]，然后提出：

> 按“教科研材料数据化分解工作流”处理这批材料，保留证据位置，禁止补造数据，完成后写入教科研数据仓库。

## 适用输入

| 材料类型 | 典型文件 | 分解重点 |
|---|---|---|
| 观点或综述文章 | PDF、网页、Word | 区分作者观点、引用证据与实证数据 |
| 实证研究论文 | 期刊论文、会议论文 | 样本、工具、变量、数据、分析与结论 |
| 硕博论文 | 完整论文、附录、数据表 | 研究设计、量表、访谈提纲、编码、统计表和附录 |
| 完整课题资料 | 申报、中期、过程、结题、成果包 | 多文件版本、目标变化、过程证据、数据与成果一致性 |
| 教案等教学材料 | 教案、课件、学习单、试卷、量规、任务书、资源包 | 目标—任务—活动—评价—证据一致性及可产生的课堂数据 |

## 总流程

```mermaid
flowchart LR
    A["材料接收"] --> B["清点与分流"]
    B --> C["文本化与定位"]
    C --> D["研究逻辑提取"]
    D --> E["数据资产盘点"]
    E --> F["变量与方法审计"]
    F --> G["主张—证据链"]
    G --> H["数据缺口与复用"]
    H --> I["结构化入库"]
    I --> J["独立对照复核"]
    J --> K["修正与完成验收"]
```

## 阶段 0：接收、安全与授权

### 操作

1. 建立处理批次，复制 [[../90_模板/教科研材料数据化分解批次模板]]。
2. 登记文件名、格式、来源、版本、用途和版权/使用范围。
3. 检查学生姓名、学号、联系方式、面部、声音和学校内部敏感信息。
4. 未脱敏材料不得提交给外部 AI；身份对应表不得进入本仓库。
5. 原件只读保存，不覆盖。

### 阶段门 G0

- [ ] 输入文件清单完整。
- [ ] 权限和敏感级别明确。
- [ ] 需要脱敏的材料已经处理。

## 阶段 1：材料清点与分流

### 操作

- 判断材料属于观点/综述、实证论文、硕博论文还是完整课题资料。
- 教案、课件、学习单、试卷、评价量规、实验任务书、学生作品范例和课程资源包进入“教学材料分支”。
- 单篇或批量参考文献进入 [[../30_研究资料/03_参考文献/参考文献数据整理入口|参考文献数据整理入口]]，完成查重、元数据核验、数据方法提取和引用状态管理。
- 完整课题按“申报—研究设计—过程—数据—分析—结题—成果”排序。
- 识别重复文件、不同版本、缺失附件和无法打开的文件。
- 建立“文件—内容角色—版本—后续用途”清单。

### 阶段门 G1

- [ ] 每个文件都有唯一编号。
- [ ] 主版本和历史版本已区分。
- [ ] 缺失文件已列入待补清单。

## 阶段 2：文本化与证据定位

### 操作

- 对 PDF、Word、表格、图片或扫描件提取可检索文本。
- 保留页码、章节、表号、图号、附录号和文件编号。
- OCR 结果必须与原图抽查核对。
- 表格不得只转成自然语言，必须保留表头、单位和数据关系。

### 阶段门 G2

- [ ] 关键内容可以回到原文件准确定位。
- [ ] OCR、表格和公式的高风险位置已复核。
- [ ] 没有把 AI 转述当成原文。

## 阶段 3：研究逻辑提取

按以下结构提取：

1. 现实问题与研究背景。
2. 研究目标、研究问题和假设。
3. 理论基础和核心概念。
4. 研究对象、场景、周期和样本。
5. 干预措施或教学策略。
6. 概念的操作性定义和可观察指标。

### 阶段门 G3

- [ ] “作者明确写出”与“分析者推断”已经分开。
- [ ] 每个研究问题都能对应潜在证据。
- [ ] 抽象概念已转换为可观察指标或标记为未定义。

## 阶段 4：数据资产盘点

逐项登记材料实际出现、声称使用和应该存在的数据：

| 数据类别 | 高中技术与工程常见内容 |
|---|---|
| 量化数据 | 前后测、成绩、量规评分、问卷、完成率、时间、成本、测试读数 |
| 质性数据 | 访谈、观察、开放回答、教师日志、学生反思、教研记录 |
| 学生交流数据 | 课堂问答、个别辅导、作品反馈、小组指导、课后交流和合规线上沟通 |
| 工程过程数据 | 草图、工程图、CAD、方案版本、决策矩阵、原型、测试和迭代记录 |
| 教学实施数据 | 教师干预、课堂活动、资源条件、实施忠实度、安全记录 |
| 外部证据 | 文献、政策、课程标准、同行案例和专家意见 |

每项数据至少记录：来源、产生者、采集时间、工具、样本、字段/单位、原始位置、处理过程、版本、敏感级别和可复核性。

### 阶段门 G4

- [ ] “实际呈现”“作者声称存在”“推断应该存在”使用不同状态标记。
- [ ] 数据来源和原始位置可追溯。
- [ ] 缺失数据保持缺失，没有补造。

## 教学材料专用分支：把“教学设计”转成“可采集数据”

> [!warning] 关键区别
> 教案、课件和学习单描述的是计划、任务与预期证据，不代表课堂已经真实发生。教学材料产生的是“设计数据”和“数据采集机会”；课堂实施后还必须用真实教学数据验证。

### A. 材料结构数据

- 课题、模块、年级、课时、版本和适用场景。
- 课程标准条目、核心素养、学习目标和重难点。
- 教学阶段、任务、资源、时间、师生活动和技术工具。
- 评价方式、评分规则、作业和预期成果。

### B. 目标—活动—评价一致性

| 学习目标 | 对应任务/活动 | 预期学生表现 | 评价工具 | 可形成的真实数据 | 一致性 |
|---|---|---|---|---|---|
| | | | | | 强/中/弱/缺失 |

### C. 教学任务的数据化

每个任务拆成：输入条件、学生动作、过程节点、预期产物、成功标准、错误类型、教师干预点和可记录字段。

### D. 技术与工程专属过程

- 问题情境是否真实，用户与需求是否明确。
- 是否要求学生识别功能、材料、成本、安全、时间等约束。
- 是否保留多方案生成、比较、决策与权衡证据。
- 是否安排草图、工程图、CAD、模型或原型等表达数据。
- 是否明确测试指标、测试条件、失败记录和迭代依据。
- 是否能够记录团队分工、项目进度、技术伦理和可持续性。

### E. 数据采集设计

- 应记录的量化数据：时间、次数、得分、成本、尺寸、性能、完成率等。
- 应记录的质性数据：学生解释、设计理由、错误、协作、教师观察和反思。
- 需要的工具：观察表、作品量规、测试记录表、学习日志、访谈或问卷。
- 采集时间点：课前基线、课堂过程、作品完成、测试迭代、课后反思和延迟迁移。

### F. 设计缺口

- 目标不可观察或无法评价。
- 活动与目标没有直接关系。
- 只有最终作品，没有过程证据。
- 评价只有总分，没有行为锚点和评分依据。
- 设计了数据采集，但没有说明工具、频率、责任人或保存方式。
- 把教师讲授完成等同于学生已经学会。

### 教学材料阶段门 GT

- [ ] 已明确区分设计数据、预期数据和真实实施数据。
- [ ] 每个学习目标都对应活动、产物、评价和可采集证据。
- [ ] 工程设计过程中的方案、制作、测试和迭代可以留下记录。
- [ ] 已输出实际课堂需要新增的记录工具和字段。
- [ ] 未把教案中的预设效果写成已经验证的研究结论。

## 阶段 5：变量、工具与方法审计

### 变量与指标

- 自变量、因变量、控制变量、背景变量和潜在混杂因素。
- 指标定义、单位、允许值、评分规则和缺失规则。
- 技术与工程重点指标参考 [[../00_HOME/高中技术与工程学科数据字典]]。

### 工具审计

- 量表、问卷、测试卷、访谈提纲、观察表和作品量规是否提供。
- 工具来源、修订过程、信度、效度和评分者一致性是否说明。

### 方法审计

- 研究问题与方法是否匹配。
- 样本和分组是否支持结论。
- 统计或质性编码过程是否透明。
- 是否存在选择偏差、测量偏差、实施偏差或选择性报告。

### 阶段门 G5

- [ ] 每个变量有定义或明确标记“定义缺失”。
- [ ] 研究方法能够连接到具体数据。
- [ ] 质量风险和替代解释已登记。

## 阶段 6：建立主张—证据链

每条重要结论建立一行：

| 主张 | 原始数据 | 处理与分析 | 证据位置 | 反例/限制 | 支持程度 |
|---|---|---|---|---|---|
| | | | | | 强/中/弱/不支持 |

### 判定原则

- 数据存在不等于支持结论。
- 显著性不等于教育意义。
- 相关关系不能自动解释为因果关系。
- 没有呈现的过程不能被视为已经完成。
- 作者观点、受访者观点和研究结论必须分开。

### 阶段门 G6

- [ ] 每个核心主张至少链接一项具体证据。
- [ ] 证据位置能够复核。
- [ ] 反例、限制和过度推论已标出。

## 阶段 7：数据缺口与复用设计

### 数据缺口

- 声称使用但没有呈现的数据。
- 缺少基线、对照、复测或过程记录。
- 缺少工具原件、评分标准或编码规则。
- 缺少原始读数，只呈现汇总结果。
- 结论超出样本、情境或研究周期。

### 复用设计

- 可借鉴的研究问题和研究主题。
- 可改造的变量、量规、问卷、观察表和访谈提纲。
- 在自己课堂中需要重新采集的真实数据。
- 可以开展的复现、扩展、对照或行动研究。
- 对高中技术与工程教学的迁移条件和风险。

### 阶段门 G7

- [ ] 已形成“可直接借鉴—需修改—不可使用”三类清单。
- [ ] 新研究方案明确需要重新采集的数据。
- [ ] 没有把他人数据冒充为自己的现场数据。

## 阶段 9：独立复核、修正与完成判定

### 复核基准

- 原始十层级参照：[[../30_研究资料/08_材料分解/教科研材料数据化分解十层级原始参照]]。
- 执行检查表：[[教科研材料数据化分解复核对照材料]]。
- 每批复核记录：[[../90_模板/教科研材料数据化复核记录模板]]。

### 复核原则

1. 复核必须回到原始文件，不得只看摘要和分解报告。
2. 尽量由另一名人员、另一次独立会话或清空前次结论后执行。
3. 对基础信息、研究逻辑、数据清单、数据来源、变量指标、方法、证据链、缺口、复用价值和入库结果逐层判定。
4. 状态只使用“通过、部分通过、不通过、不适用、待补材料”。
5. 不一致项必须记录原文位置、严重程度、修正动作和关闭状态。

### 必须人工核验

- 标题、作者、年份、机构、DOI、文号等元数据。
- 引文、页码、表号、图号、统计数字和样本量。
- AI 摘要、OCR、表格识别和质性编码结果。
- 主张支持程度、因果判断、伦理风险和最终结论。

### 完成标准

只有同时满足以下条件，才可标记 `status: completed`：

- [ ] 原始材料与文件清单完整或已说明缺失。
- [ ] 研究逻辑、数据资产、变量和方法已经拆解。
- [ ] 教学材料已检查目标—活动—评价—证据一致性，并生成真实数据采集建议。
- [ ] 涉及学生交流的数据已匿名化，并区分原话、概述和解释。
- [ ] 核心主张都有证据位置和支持程度。
- [ ] 数据缺口、反例和限制已经报告。
- [ ] AI 生成内容均有核验状态。
- [ ] 已建立独立复核记录，十个层级逐项完成对照。
- [ ] 所有高严重度不一致项已修正或明确接受限制。
- [ ] 无编造数据、文献、引文、页码或政策条款。
- [ ] 无不必要的个人敏感信息。
- [ ] 输出已经写入正确分类，双链无断链。

## 异常处理

| 异常 | 处理方式 |
|---|---|
| 文件打不开或加密 | 停止该文件处理，登记问题并请求可读版本 |
| 扫描质量差 | 标记低可信区域，人工核对原图，不猜测文字或数字 |
| 附录/数据缺失 | 标记“作者声称存在但未获得”，不得模拟补齐 |
| 多版本冲突 | 保留所有版本，按日期和来源确定主版本，记录差异 |
| 结论与数据矛盾 | 同时保留，进入反例与方法审计，不替作者消除矛盾 |
| 涉及学生敏感信息 | 先停止外部 AI 处理，完成脱敏和权限确认 |

## 标准交付摘要

每批材料完成后报告：材料数量、材料类型、核心研究问题、数据资产数量、主张证据链数量、重要数据缺口、可复用方向、独立复核结论、未关闭问题和入库文件路径。
