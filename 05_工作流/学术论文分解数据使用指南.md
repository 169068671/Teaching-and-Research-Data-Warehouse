# 学术论文分解数据使用指南

> [!important] 本指南解决什么问题
> 学术论文按"学术论文教科研数据分解工作流-Zcode版"分解后,会产出十几个文件。本指南说明这些文件分别能怎么用、在写文章或做研究时如何调用,以及使用的边界和禁忌。

## 一、分解数据的全景

一篇论文完整分解后,你有以下数据资产:

| 数据域 | 核心产物 | 文件位置 |
|---|---|---|
| 元数据 | 来源总卡 CSV | `30_研究资料/03_参考文献/引用映射` |
| 参考文献与引用 | 参考文献总表、规范化实体、正文引用位置、映射JSON、映射报告、引用内容明细、映射复核 | `30_研究资料/03_参考文献/引用映射` |
| 研究逻辑 | 总报告第3章 | `30_研究资料/08_材料分解` |
| 数据资产 | 数据资产清单 CSV、量化结果 CSV、结构化数据表 | `30_研究资料/08_材料分解/数据表` |
| 变量工具方法 | 总报告第5-6章、内部不一致 CSV | 同上 |
| 主张证据链 | 主张证据链 CSV + MD | `50_分析与成果/02_证据链` |
| 缺口与复用 | 数据缺口 CSV、迁移数据规划 MD | `30_研究资料/08_材料分解/数据表` + `40_真实数据/01_数据规划` |
| 复核记录 | 数据化分解复核、参考文献映射复核 | `30_研究资料/08_材料分解` |

## 二、五种典型使用场景

### 场景1:写文献综述

**目标**:梳理某领域的文献分布、核心观点、研究脉络。

**调用数据**:

| 数据文件 | 怎么用 |
|---|---|
| `论文简称_规范化文献实体.csv`(多篇) | 合并多篇论文的被引文献,按题名去重,得到该领域的文献池;共引文献是基石,独引文献显示视角差异 |
| `论文简称_正文引用位置.csv` | 看每篇文献在论文里承担的作用(概念界定/理论基础/方法来源),统计引用用途分布 |
| `论文简称_引用内容明细.md` | 直接看引用方怎么转述每篇文献的观点,写综述时对照自己的理解,避免误读 |
| `论文简称_参考文献总表.csv` | 查每篇文献的完整书目、引用次数、出现页码,用于排版参考文献列表 |

**操作步骤**:

1. 把多篇论文的规范化文献实体 CSV 合并,按题名或DOI去重。
2. 标注每篇文献被哪些论文引用(共引vs独引)。
3. 按主题分组(如创客教育/校本课程/3D打印应用/理论基础)。
4. 用引用内容明细 MD 查每篇文献的核心观点。
5. 用正文引用位置 CSV 统计引用分布,判断该领域的研究重心。
6. 写综述时,引用观点要回原文核验(引用内容明细是转述,不是原文)。

### 场景2:设计自己的研究

**目标**:借鉴已有研究的设计,避免重复错误,填补研究空白。

**调用数据**:

| 数据文件 | 怎么用 |
|---|---|
| 总报告第3章研究逻辑 | 看研究问题、假设、理论框架,借鉴或改进 |
| 总报告第5章变量字典 | 看变量怎么定义,避免构念不清(如"创新思维"vs"跨学科思维"混用) |
| 总报告第6章工具审计 | 看量表、问卷、评价工具,哪些可直接用、哪些要改 |
| `论文简称_论文报告量化结果.csv` | 抽样公式、样本量、统计方法可直接参考 |
| `论文简称_数据缺口.csv` | 找研究空白——她们缺什么,你就补什么 |
| `迁移XXX论文的高中技术与工程真实数据规划.md` | 已经规划好你要采集什么数据,直接用 |

**操作步骤**:

1. 合并多篇论文的数据缺口表,找共同缺口(如两篇都缺"无对照组""无前测")。
2. 针对共同缺口提出你的研究问题。
3. 查工具审计表,选可借鉴的工具(如蔡明辉的问卷14题结构),标记需要改进的地方(如补信效度)。
4. 查变量字典,明确你的因变量定义,避免构念漂移。
5. 查迁移数据规划,确定你要采集的数据清单。
6. 写研究方法时,明确标注哪些设计借鉴了哪篇论文、做了什么改进。

### 场景3:写实证研究文章

**目标**:基于自己的课堂数据写文章,引用已有研究作为对照和支撑。

**调用数据**:

| 数据文件 | 怎么用 |
|---|---|
| `论文简称_主张证据链.csv` + MD | 引用他人结论时,查支持程度(强/中/弱/不支持),措辞要匹配 |
| `论文简称_论文报告量化结果.csv` | 与自己的数据做横向对照(如你的合格率vs她的合格率) |
| 总报告第7章主张证据链 | 看每条结论的证据位置和反例,避免选择性引用 |
| `论文简称_内部不一致.csv` | 避免重复她们的错误(如因变量漂移、实施范围不清) |

**操作步骤**:

1. 写引言时,用数据缺口表说明"现有研究缺什么"。
2. 写文献综述时,用引用内容明细和主张证据链,标注每条引用结论的支持程度。
3. 写研究方法时,借鉴工具审计表里可用的工具,标注改进点。
4. 写结果讨论时,用量化结果 CSV 与自己的数据做对照。
5. 写结论时,查内部不一致表,确保你的研究目标、问题、结论里的变量名称前后一致。

**关键措辞规则**:

| 支持程度 | 引用措辞示例 |
|---|---|
| 强 | "蔡明辉(2019)的研究表明,大部分学生能够掌握3D One软件基本操作" |
| 中 | "蔡明辉(2019)报告称约30%学生对课程感兴趣,但该研究无前测基线" |
| 弱 | "蔡明辉(2019)认为课程有助于创新思维发展,但其研究无对照组,结论有待进一步验证" |
| 不支持 | "该研究声称提升了问题解决能力,但正文未呈现对应数据" |

### 场景4:写教学反思或案例文章

**目标**:借鉴已有课程设计,反思自己的教学实践。

**调用数据**:

| 数据文件 | 怎么用 |
|---|---|
| 总报告第3.6节干预与课程结构 | 借鉴课程框架(如蔡明辉的"需求—目标—内容—实施—评价—完善"流程) |
| 总报告第9章教学材料附加分析 | 看目标—活动—评价—证据矩阵,检查自己的课程一致性 |
| 总报告第10章复用价值 | 分三类:可直接借鉴/需修改后使用/不建议直接使用 |
| 总报告第4章数据资产清单 | 看她们的课程产生了哪些数据,你的课程可以采集什么 |

**操作步骤**:

1. 查复用价值表,选可直接借鉴的部分(如三阶段结构、期末作品任务设计)。
2. 查需修改的部分,标注你要怎么改(如把模仿设计升级为多方案生成)。
3. 查教学材料附加分析的目标—活动—评价矩阵,用同样框架检查你的课程。
4. 查数据资产清单,看你的课堂可以采集哪些她们没有的数据(如工程过程数据)。
5. 写反思时,用内部不一致表提醒自己避免同样的口径冲突。

### 场景5:写方法论文章

**目标**:总结某类研究的方法问题,提出改进建议。

**调用数据**:

| 数据文件 | 怎么用 |
|---|---|
| 总报告第6章工具与方法审计 | 汇总多篇论文的工具问题(如问卷无信效度、作品评价无评分者一致性) |
| `论文简称_内部不一致.csv` | 汇总方法层面的不一致(如实施范围与调查范围混淆、因变量漂移) |
| `论文简称_数据缺口.csv` | 汇总方法层面的缺口(如无对照、无前测、无原始数据) |
| 总报告第6.5节专项审计 | 看统计量不全、量表结构问题、小样本信效度混用等专项问题 |

**操作步骤**:

1. 合并多篇论文的方法审计表,找共同方法问题。
2. 按问题类型分类(设计缺陷/工具缺陷/统计缺陷/报告缺陷)。
3. 针对每类问题提出改进建议。
4. 用内部不一致表和缺口表作为问题证据。

## 三、进入仓库的路径

```
写文章时,按需进入:

30_研究资料/03_参考文献/参考文献数据整理入口.md
  → 论文文献卡(元数据)
  → 引用映射目录(7个文件/篇,含引用内容明细)

30_研究资料/08_材料分解/
  → 总报告(研究逻辑、数据资产、变量工具、主张证据链、缺口、复用)
  → 数据表目录(数据资产清单、量化结果、数据缺口、内部不一致 CSV)
  → 复核记录

50_分析与成果/02_证据链/
  → 主张证据链 CSV(机器索引) + MD(人工展开)

40_真实数据/01_数据规划/
  → 迁移数据规划(你要采集什么数据)
```

## 四、数据使用的边界与禁忌

### 必须遵守

1. **引用结论必须标注支持程度**——不能把"弱支持"写成"研究表明"。
2. **不能把她们的数据当你的数据**——迁移规划已明确"来源论文数据不得作为本课堂数据使用"。
3. **工具借鉴要核验**——她们的量表可能有结构问题(如蔡明辉问卷无信效度分析)。
4. **参考文献要回原文核验**——引用内容明细里是"引用方转述的话",不是被引文献原文;正式引用前必须查原文。
5. **保留证据位置**——引用他人结论时,标注论文页码和证据位置,可追溯。

### 禁止行为

- 禁止把"弱支持"的因果结论当作"已证实"。
- 禁止把课后兴趣当兴趣提升。
- 禁止把自陈数据当客观能力。
- 禁止把选择性作品样例当全体质量。
- 禁止把单校单学期的结论推广到所有学校。
- 禁止不标注支持程度就引用他人结论。
- 禁止把他人数据冒充为自己的现场数据。

## 五、多论文数据的合并与对比

当你有多篇论文的分解数据时,可以做横向对比:

### 5.1 文献池合并

把多篇论文的 `论文简称_规范化文献实体.csv` 合并:

1. 按题名或DOI去重。
2. 标注每篇文献被哪些论文引用。
3. 共引文献(多篇都引)是该领域基石。
4. 独引文献显示各论文的视角差异。

### 5.2 方法问题汇总

把多篇论文的内部不一致表和数据缺口表合并:

1. 找共同方法问题(如多篇都缺对照组)。
2. 找独特方法问题(某篇特有的设计缺陷)。
3. 共同问题说明该领域的普遍短板,你的研究可以针对这些短板。

### 5.3 结论对照

把多篇论文的主张证据链合并:

1. 找相同主张的不同支持程度(如两篇都谈"课程提升创新思维",但支持程度不同)。
2. 找矛盾结论(如周宗萍报告P=0.002显著,蔡明辉无统计检验)。
3. 矛盾结论是研究机会,你的研究可以验证哪个成立。

截至 2026-07-27,仓库内有以下论文的完整分解:

| 论文 | 类型 | 分解文件数 | 关键数据 |
|---|---|---|---|

| 蔡明辉《高中3D打印校本课程的开发与实践研究》 | 硕士论文 | 15个 | 29编号28实体29引用、26类数据资产、12条主张证据链、55项量化结果 |

两篇论文的合并潜力:

- 文献池:43+28=71篇,去重后约60-65篇独立文献。
- 共同主题:3D打印校本课程开发。
- 可对比维度:小学vs高中、单班27人vs单校7班、有前后测vs无前后测。
- 共同缺口:无对照组、无工程过程数据、无评分者一致性。
