# 原始资料说明

此目录保存 PDF、Office、图片、音视频、CSV 等原始文件。每个重要原始文件必须有一条 Markdown 登记笔记，说明来源、版本、用途和访问限制。

## 安全要求

- 只保存研究所必需的数据。
- 学生姓名、学号、联系方式、面部和声音等信息先脱敏。
- 身份对应表、家长联系方式等高敏感材料不得放入本仓库。
- 不上传无授权的受版权保护资料；文献优先保存合法链接和个人研究笔记。
- 到期数据按研究方案和学校规定归档或销毁。
