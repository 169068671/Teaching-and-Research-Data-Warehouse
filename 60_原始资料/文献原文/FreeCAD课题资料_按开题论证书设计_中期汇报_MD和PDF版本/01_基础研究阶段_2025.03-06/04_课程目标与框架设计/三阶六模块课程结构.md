# 三阶六模块课程结构

> 依据：开题论证书"三、研究目标与内容" + "五、研究成果"，并按开发设计阶段的新网站、新PPT落实为21课时课堂主序列。
> 开题阶段66学时为总体容量设想；现行执行口径为21课时（2+3+4+4+4+4），每课时45分钟。

## 三阶六模块总览

| 阶段 | 能力目标 | 模块 | 课时 |
|---|---|---|---|
| 基础启蒙 | 技术认知 + 安全意识 | 模块一：3D打印新视界与STEAM启蒙 | 2 |
| 技术实践 | 手动建模 | 模块二：手动建模基础与实践（FreeCAD） | 3 |
| 技术实践 | 参数化与循环建模 | 模块三：编程建模入门与逻辑构建 | 4 |
| 技术实践 | 结构设计 + 原生装配 | 模块四：结构设计与原生装配 | 4 |
| 技术实践 | 跨学科工程验证 | 模块五：桥梁跨学科项目、有限元与打印验证 | 4 |
| 综合创新 | 系统设计 + 工程迭代 + 展评反思 | 模块六：综合STEAM项目设计与成果展示 | 4 |
| **合计** | | | **21课时** |

## 各模块详细内容（依据论证书原文）

### 模块一：3D打印新视界与STEAM启蒙
课程介绍，STEAM理念，3D打印技术原理、类型、应用场景，编程思维启蒙，安全教育等。

### 模块二：手动建模基础与实践（以FreeCAD为例）
FreeCAD软件界面、基本操作、视图控制、文件管理、基础几何体建模、简单组合建模练习等。

### 模块三：编程建模入门与逻辑构建
编程建模平台介绍（如集成于FreeCAD的编程模块或专门的编程建模软件）、编程基础（变量、循环、条件、函数等）、用编程控制几何体生成与变换等。

### 模块四：结构设计与原生装配
第10—13课完成手机支架和带盖储物盒：从需求、倾角、承托、重心与间隙参数出发，完成结构建模、干涉检查，并使用FreeCAD原生Assembly工作台进行约束和运动验证。

### 模块五：桥梁跨学科项目、有限元与打印验证
第14—17课围绕同一座正弦拱桁架桥形成“函数建模—传力分析—FreeCAD FEM/CalculiX仿真—Cura切片—打印—承重试验”的完整证据链。

### 模块六：综合STEAM项目设计与成果展示
选题（结合生活、科技、艺术等）、项目规划、团队协作、融合手动、编程建模与3D打印技术完成综合项目、成果展示与答辩、项目反思。

## 能力进阶路径

```
第1-2课 基础启蒙         第3-17课 技术实践                第18-21课 综合创新
3D打印认知与安全         手动/编程/装配/FEM/打印           自主选题、迭代、证据与展评
```

## 创新特性

每层级配备"微认证"达标机制与"弹性挑战"扩展包，实现"保底不封顶"的分层教学。
