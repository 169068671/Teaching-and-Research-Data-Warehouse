## 二、研究（依据开题论证书）

### 2.1 研究思路

> "理论构建→需求分析→课程开发→实践检验→迭代优化→成果固化"的螺旋式行动研究路径，依托项目式学习（PBL），深度融合STEAM理念，将编程建模与3D打印技术作为核心实践载体。

STEAM融合遵循开题论证书“不是学科的简单叠加”原则：各模块、各作业只标注真实发生的一个或几个融合点，综合项目再根据选题形成多领域融合。现行对应关系见 `02_开发设计阶段_2025.07-12/01_课程标准与资源包/STEAM融合点对照说明_依据开题论证书.md`。

### 2.2 三阶六模块课程结构（现行21课时）

| 阶段 | 能力目标 | 模块 | 课时 |
|---|---|---|---|
| 基础启蒙 | 技术认知 + 安全意识 | 模块一：3D打印新视界与STEAM启蒙 | 2 |
| 技术实践 | 手动建模 + 编程建模 + 工程验证 | 模块二：手动建模基础（FreeCAD）<br>模块三：编程建模入门与逻辑构建<br>模块四：结构设计与原生装配<br>模块五：桥梁跨学科项目、有限元与打印验证 | 3+4+4+4 |
| 综合创新 | 系统设计 + 工程迭代 + 展示反思 | 模块六：综合STEAM项目设计与成果展示 | 4 |
| **合计** | | | **21课时（每课时45分钟）** |

> 开题论证书中的“20+30+16=66学时”是立项时的总体课程容量设想；现行课堂资源已经收敛为21课时实施主序列。送审时应同时说明“规划容量”与“当前实施课时”，不得混写为同一口径。

### 2.3 四阶段研究计划

| 阶段 | 时间 | 核心任务 |
|---|---|---|
| 基础研究 | 2025.03—2025.06 | 文献分析、需求调研、硬件评估、目标设计 |
| 开发设计 | 2025.07—2025.12 | PBL项目链设计、资源包开发、教师培训方案 |
| 实践验证 | 2026.01—2026.12 | 实验班实施、教研复盘、数据采集 |
| 成果固化 | 2027.01—2027.06 | 对比测评、指标体系、校本教材、推广方案 |

### 2.4 研究目标

1. 构建"三阶六模块"课程结构，明确各模块学时分配与能力进阶路径
2. 开发配套资源包（含30个教学案例、20项实践任务卡、多元化评价量表），完成教师指南与学生手册编写
3. 通过为期1年的教学实践，验证课程对学生创新思维（提升20%）、计算思维（达标率≥85%）的促进效果
4. 形成可推广的校本课程开发范式，为同类学校提供参考

### 2.5 六模块内容（依据开题论证书"三、研究内容"）

| 模块 | 名称 | 内容 |
|---|---|---|
| 模块一 | 3D打印新视界与STEAM启蒙 | 课程介绍，STEAM理念，3D打印技术原理、类型、应用场景，编程思维启蒙，安全教育 |
| 模块二 | 手动建模基础与实践（以FreeCAD为例） | FreeCAD软件界面、基本操作、视图控制、文件管理、基础几何体建模、简单组合建模 |
| 模块三 | 编程建模入门与逻辑构建 | 编程建模平台介绍（集成于FreeCAD的编程模块）、编程基础（变量、循环、条件、函数）、用编程控制几何体生成与变换 |
| 模块四 | 结构设计与原生装配 | 手机支架需求与参数、结构建模与验证；带盖储物盒槽口间隙、多实体设计、FreeCAD原生Assembly约束与运动验证 |
| 模块五 | 桥梁跨学科项目、有限元与打印验证 | 正弦拱桁架桥、传力路径、FreeCAD FEM与CalculiX、STL检查、Cura切片与支撑、打印承重试验及仿真—实测对照 |
| 模块六 | 综合STEAM项目设计与成果展示 | 自主选题、方案设计、项目建模与迭代、切片打印、证据文档、并行展评与项目反思 |
