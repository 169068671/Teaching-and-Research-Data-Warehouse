文件管理

新建(Ctrl+N) · 保存(Ctrl+S) · 命名规范

# Python控制台新建文档
import FreeCAD
doc = FreeCAD.newDocument('MySketch')
print('文档已创建：', doc.Name)
作用newDocument()新建文档，返回值存入doc，后续草图和实体都添加到doc。
结果对象树出现MySketch；控制台输出文档名，但尚未保存成FCStd。
易错点同名文档可能冲突；运行后仍要Ctrl+S并按规范命名。

Pad拉伸特征

把2D草图拉成3D实体

# 创建Pad
pad = body.newObject('PartDesign::Pad', 'Pad')
pad.Profile = sketch
pad.Length = 3.0  # 拉伸3mm
doc.recompute()
逐行作用新建Pad → 指定闭合草图Profile → 设置3mm高度 → recompute生成实体。
前置条件body和sketch必须已存在，且sketch是Body内无缺口、无自交的闭合轮廓。
易错点草图未闭合或Profile指错时Pad失败；Length单位为mm。
🕳️

Pocket挖孔特征

在实体上挖孔（反向Pad）

  • 1. 在实体表面创建新草图
  • 2. 画孔的形状（圆/矩形）
  • 3. 点击Pocket按钮
  • 4. 设置深度→确认
