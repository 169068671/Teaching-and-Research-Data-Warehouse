参数化设计

所有尺寸用变量，改变量就改模型

box_L = 60          # 盒体长度
wall_T = 2.5        # 盒体壁厚
groove_W = 3.2      # 盒盖环形槽宽
clearance = 0.35    # 单侧装配间隙
作用把关键尺寸集中为变量，后续几何只引用变量，修改参数即可更新模型。
单位长度统一使用mm；clearance=0.35表示单侧间隙。
易错点变量名要前后一致；槽宽必须由壁厚和两侧间隙联动计算。
➕

fuse布尔并

合并两个几何体

import FreeCAD
import Part
box = Part.makeBox(45, 20, 3)
ring = Part.makeCylinder(7, 3, FreeCAD.Vector(45, 10, 0))
body = box.fuse(ring)  # 合并
Part.show(body)
逐行作用创建矩形主体和圆柱挂环，Vector把圆柱移到主体端部，fuse执行布尔并。
运行结果两个相交几何体合成body；Part.show()将结果显示到3D视图。
易错点几何体必须接触或重叠；若分离，结果可能包含多个Solid。
➖

cut布尔差

从一个几何体减去另一个

import FreeCAD
import Part
outer = Part.makeBox(60, 40, 35)
inner = Part.makeBox(55, 35, 33,
                     FreeCAD.Vector(2.5,2.5,2.5))
box_body = outer.cut(inner)  # 形成有底盒体
Part.show(box_body)
逐行作用先建外盒，再把内盒向XYZ各偏移2.5mm，outer.cut(inner)挖出内腔。
运行结果四周壁厚2.5mm、底厚2.5mm；内盒顶面高于外盒，顶部保持开口。
易错点内盒必须与外盒相交且不能过大；偏移为0会把侧壁或底部挖穿。

多实体与装配间隙

盒体、盒盖保持独立，盒沿进入环形槽

groove_W = wall_T + 2 * clearance
# 2.5 + 2×0.35 = 3.2mm
# 两侧各留0.35mm，避免零间隙干涉
公式槽宽=插入边厚度+左间隙+右间隙=2.5+0.35×2=3.2mm。
设计含义槽宽控制配合松紧；槽深控制插入深度，两者不可混用。
易错点0.35是单侧间隙，不是总间隙；打印前要用间隙测试块校准。
