# 课程方案PDF与开题论证书差异说明

> [!important] 重要说明
> 本目录下的4个课程方案PDF和02_六模块教学设计目录下的旧版模块PDF，是课题早期制作的旧版本（基于20课时/32学时旧版结构）。
> 当前实施版依据教学复盘调整为**六模块/21课时**：模块一2课时、模块二3课时、模块三4课时、模块四4课时、模块五4课时、模块六4课时。
> 三阶66学时是开题论证书中的课程开发总体规模；21课时是本资源包可直接实施的课堂主序列，两者统计口径不同。
> 以下早期PDF内容与新网站（`新网站/`）和新PPT（`新PPT/`）的六模块21课时实施结构不一致，须以当前实施版为准。
> 送审时以**开题论证书**和**新网站/新PPT**为准，旧PDF作为保留对照。

## 差异对照

| 项目 | 旧PDF内容 | 现行实施口径 |
|---|---|---|
| 课时数 | 20课时/32学时 | **21课时（2+3+4+4+4+4）** |
| 学时分配 | 32学时（16周×2学时） | **21课时，每课时45分钟**；66学时仅作为开题规划容量另行说明 |
| 模块数 | 旧版模块结构（含独立毕业项目模块） | **六模块**（毕业项目归入模块六） |
| 模块一名称 | 走进三维世界 | **3D打印新视界与STEAM启蒙** |
| 模块二名称 | 二维是基础 | **手动建模基础与实践（以FreeCAD为例）** |
| 模块三名称 | 从平面到立体 | **编程建模入门与逻辑构建** |
| 模块四名称 | 让模型更精致 | **结构设计与原生装配** |
| 模块五名称 | 组合的力量 | **桥梁跨学科项目、有限元与打印验证** |
| 模块六名称 | 从虚拟到现实 | **综合STEAM项目设计与成果展示** |
| 旧版独立毕业项目模块 | 毕业项目（独立模块） | **已取消，归入模块六** |
| 装配工具 | A2plus | **FreeCAD原生Assembly工作台** |
