🧭 倾斜方向检查

从侧视图观察：背板顶部应远离挡唇，使手机向后依靠；若顶部向挡唇靠近，就是倾斜反了。

# 布尔并：把相交的底座和挡唇合成一个实体
import FreeCAD
import Part
base = Part.makeBox(80, 50, 10)
lip = Part.makeBox(80, 6, 12, FreeCAD.Vector(0, 0, 10))
stand = base.fuse(lip)

# 布尔差：从主体中减去充电线开口
cable = Part.makeBox(14, 10, 8, FreeCAD.Vector(33, 0, 6))
stand = stand.cut(cable).removeSplitter()
Part.show(stand)

代码解读

  1. base创建80×50×10mm底座；lip通过Vector(0,0,10)放到底座顶面。
  2. base.fuse(lip)执行布尔并。两个几何体必须有真实接触或重叠，才能形成连续实体。
  3. cable是14mm宽的切削工具体，位置在挡唇中部。
  4. stand.cut(cable)执行布尔差，生成充电线开口；removeSplitter()清理残余分割边。
运行结果：显示带挡唇和中央充电开口的单一底座。本段演示布尔运算，倾斜背板需按25°参数继续建模并合并。
易错点：若lip悬空，fuse()可能得到多个Solid；若cable没有穿过主体，cut()不会出现开口。完成后用len(stand.Solids)检查应为1。
