📐 正弦拱桁架桥设计

⏱️ 45分钟🧩 S/T/E/M融合🌉 桥梁项目

🎯 学习任务

  • 用z=16+26×sin(πx/120)生成拱肋站位
  • 识别上弦、下弦、竖腹杆、斜腹杆和横向联系
  • 画出从桥面到支座的传力路径
  • 生成单一可打印桥梁实体

📈 数学函数变成结构

7个站位沿120mm跨度均匀分布；正弦函数控制拱肋高度，交叉腹杆提高平面稳定，横向联系防止两片桁架侧向失稳。

# 计算7个正弦拱站位的x、z坐标
import math
span = 120.0
base_z = 16.0
rise = 26.0
station_count = 7

for i in range(station_count):
    x = span * i / (station_count - 1)
    z = base_z + rise * math.sin(math.pi * x / span)
    print(i, "x =", round(x, 1), "z =", round(z, 1))

代码解读

  1. station_count = 7表示包含左右端点在内共7个站位，因此跨长被分成7-1=6等份。
  2. x = span*i/(station_count-1)依次得到0、20、40、60、80、100、120mm。
  3. math.pi*x/span把跨长位置映射到0～π；sin()在两端为0、跨中为1。
  4. z = base_z + rise*sin(...)让两端高度为16mm、跨中最高为42mm，形成对称拱线。
运行结果：输出7组对称坐标，随后可把相邻站位连接为上弦，并在同一x位置建立竖腹杆。
易错点：math.sin()使用弧度，所以必须乘math.pi；分母要用station_count-1，否则最后一个站位到不了120mm端点。
