🧩 切片与支撑优化

⏱️ 45分钟🖨️ Cura🌉 桥梁项目

🎯 学习任务

  • 检查STL尺寸、法向和单一壳体
  • 选择桥面平放方向
  • 比较0.16/0.20mm层高和15/25%填充
  • 只在拱肋下方设置必要支撑
  • 记录时间、耗材和支撑体积

⚖️ 参数不是越大越好

高填充不能补偿薄弱连接；过多支撑会增加拆除损伤。先保证杆件连续和方向正确，再优化层高、填充和支撑。

# 导出当前选中的桥梁对象为STL
import FreeCAD
import FreeCADGui
import Mesh

selection = FreeCADGui.Selection.getSelection()
if not selection:
    raise RuntimeError("请先在对象树中选中桥梁对象")

file_path = FreeCAD.getUserAppDataDir() + "学号-姓名-桥梁.stl"
Mesh.export([selection[0]], file_path)
print("STL导出成功：", file_path)

代码解读

获取对象FreeCADGui.Selection.getSelection()读取对象树中当前选中的对象，返回一个列表。
错误拦截if not selection在没有选中对象时主动停止，并给出可理解的修正提示。
确定路径getUserAppDataDir()取得FreeCAD用户数据目录，再拼接规范文件名，避免路径不存在。
执行导出Mesh.export([selection[0]], file_path)取列表中的第一个对象并转换为三角网格STL。
运行结果：控制台输出STL完整路径。随后在Cura导入文件并核对跨度应为120mm、模型为单一壳体。
易错点：STL只保存表面网格，不保存参数和建模历史；导出前必须保留FCStd源文件，并确认选中的是最终桥梁而不是单根杆件。
