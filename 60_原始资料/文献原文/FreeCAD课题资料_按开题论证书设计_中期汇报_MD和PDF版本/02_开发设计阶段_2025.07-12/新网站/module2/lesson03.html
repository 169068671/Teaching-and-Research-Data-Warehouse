📁 文件管理

新建文档：菜单 → 文件 → 新建（或Ctrl+N）

保存文件：菜单 → 文件 → 保存（或Ctrl+S），保存为 .FCStd 格式

命名规范：学号-姓名-项目名.FCStd（如 01-张三-钥匙扣.FCStd）

# 用Python控制台新建文档
import FreeCAD
doc = FreeCAD.newDocument("MySketch")
print("文档已创建：", doc.Name)

代码解读

整体作用新建一个内部名称为MySketch的FreeCAD文档，并把文档对象保存到变量doc。
关键语句FreeCAD.newDocument("MySketch")相当于菜单“文件→新建”；返回值是后续添加草图和实体的容器。
运行结果对象树出现新文档，控制台输出“文档已创建： MySketch”。此时文档尚未保存到磁盘。
易错点同名文档已经打开时可能产生命名冲突；新建后仍要按Ctrl+S保存为FCStd文件。

✏️ Sketcher草图工作台

切换到Sketcher工作台：顶部工作台选择器 → Sketcher

常用草图工具：

📏 线段：画直线，点击起点和终点

⭕ 圆：画圆，点击圆心和半径

🌙 圆弧：画弧线，点击起点、终点、半径

📐 矩形：画矩形，点击对角两点

📋 创建草图步骤

1. 切换到Sketcher工作台

2. 点击"创建草图"按钮

3. 选择草图平面（XY平面 / XZ平面 / YZ平面）

4. 在平面上用工具绘制图形

5. 添加约束（第4课详细学习）

# 用Python创建草图（预览，第4课详细学）
import FreeCAD
import Part
import Sketcher
doc = FreeCAD.newDocument("SketchDemo")
sketch = doc.addObject("Sketcher::SketchObject", "Sketch")
# 画一条线段：从(0,0)到(60,0)
sketch.addGeometry(Part.LineSegment(
    FreeCAD.Vector(0, 0, 0),
    FreeCAD.Vector(60, 0, 0)
), False)
doc.recompute()
print("草图已创建，含1条线段")

代码解读

  1. import FreeCAD / Part / Sketcher：分别提供文档与坐标、线段几何、草图约束功能。
  2. doc.addObject(...)：在文档中创建名为Sketch的草图对象；未附着到实体表面时默认位于XY平面。
  3. Part.LineSegment(...)：用两个三维坐标定义线段，Z坐标均为0，所以线段落在草图平面内。
  4. sketch.addGeometry(..., False)：把线段加入草图；False表示它是普通几何，不是辅助构造线。
  5. doc.recompute()：让FreeCAD重新计算文档并刷新对象树和视图。
运行结果：新文档中出现一个Sketch对象，草图包含从(0,0)到(60,0)的一条60mm线段。
易错点：漏写import Part会导致Part.LineSegment未定义；两个端点相同会生成零长度几何；本例只有一条线，还不能Pad拉伸。
