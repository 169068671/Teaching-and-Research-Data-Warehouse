📐 几何约束与尺寸约束

⏱️ 45分钟 📖 预习必做 🎯 技术实践
📖 课前预习（必须完成）

上课前请完成以下预习任务

  • 复习第3课：确保能在Sketcher中创建草图并画线段
  • 理解"约束"概念：约束就是"规定图形之间的关系"，让图形不会随意变形
  • 思考：画一个矩形，如果不加约束，拖动一个角点会发生什么？（答案：变形）

  • 记住一个原则：先几何约束，后尺寸约束（先管形状，再管大小）
⚠️ 约束是手动建模的核心难点，不预习将无法理解约束逻辑，课堂操作会卡住。

🎯 本课教学目标

  • 理解几何约束与尺寸约束的区别
  • 掌握常用几何约束：水平、垂直、重合、相切、平行
  • 掌握尺寸约束：长度、角度、半径
  • 理解"完全约束"概念（草图不能随意变形=完全约束）
  • 能判断草图是欠约束、完全约束还是过约束

🔗 几何约束（管形状关系）

几何约束规定图形元素之间的关系，不管具体大小。

📏 水平（Horizontal）：线段保持水平方向

📐 垂直（Vertical）：线段保持垂直方向

🔵 重合（Coincident）：两个点重合在一起（角点连接）

Tangent 相切（Tangent）：线段与圆弧相切

⫼ 平行（Parallel）：两条线段保持平行

⊥ 垂直（Perpendicular）：两条线段互相垂直

📏 尺寸约束（管具体大小）

尺寸约束规定图形的具体数值。

↔️ 水平距离（DistanceX）：两点之间的水平距离（如底边长度60mm）

↕️ 垂直距离（DistanceY）：两点之间的垂直距离（如高度18mm）

🔄 角度（Angle）：两条线段之间的夹角

⭕ 半径（Radius）：圆或圆弧的半径

✅ 完全约束

完全约束 = 草图的所有自由度都被约束，图形不能随意变形。

判断方法：草图所有线段和点都变为绿色（FreeCAD中绿色=完全约束）

三种状态：

🔴 欠约束：有未约束的自由度（白色），图形可变形 → 需要加更多约束

🟢 完全约束：所有自由度被约束（绿色），图形固定 → 理想状态

🔴 过约束：约束过多产生冲突（红色），有矛盾 → 需要删除多余约束

# 用Python添加约束（前置：sketch中已有矩形线段和圆）
import Sketcher

# 几何约束
sketch.addConstraint(Sketcher.Constraint("Horizontal", 0))   # 线段0水平
sketch.addConstraint(Sketcher.Constraint("Vertical", 1))     # 线段1垂直
sketch.addConstraint(Sketcher.Constraint("Coincident", 0, 2, 1, 1))  # 角点重合

# 尺寸约束
sketch.addConstraint(Sketcher.Constraint("DistanceX", 0, 1, 0, 2, 60.0))  # 底边=60mm
sketch.addConstraint(Sketcher.Constraint("Radius", 4, 2.5))  # 几何4圆孔半径=2.5mm

代码解读

几何编号0、1、4是草图中几何元素的索引，按加入草图的先后从0开始编号，不是长度数值。
点位编号线段的1代表起点、2代表终点；Coincident(0,2,1,1)让线0终点与线1起点重合。
形状约束Horizontal和Vertical先固定方向，Coincident再连接角点，解决“形状关系”。
尺寸约束DistanceX(...,60.0)控制水平距离为60mm；Radius(4,2.5)控制第4个几何元素的半径为2.5mm。
运行结果：对应线段方向、角点连接、底边长度和圆孔半径被锁定；是否完全约束还取决于草图中其他自由度。
易错点：索引必须与自己的草图一致。若第4个元素不是圆，或几何编号超出范围，约束会报错；重复添加相同约束可能造成过约束。

🔑 约束口诀

先几何，后尺寸

先形状，后大小

看颜色，判状态

白=欠约束，绿=完全约束，红=过约束
