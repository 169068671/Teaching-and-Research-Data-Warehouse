🔁 for循环

for i in range(n): 重复执行n次。

i从0开始，每次加1，到n-1结束。

用途：批量创建几何体（如乐高积木顶部8个圆柱）。

📦 def函数

def 函数名(参数): 定义函数。

函数可以重复调用，避免代码重复。

参数让函数更灵活——传不同参数得到不同结果。

# 实践作业3：用双重循环创建2×4凸点阵列
import FreeCAD
import Part

brick = Part.makeBox(31.8, 15.8, 9.6)
for row in range(2):
    for col in range(4):
        stud = Part.makeCylinder(
            2.45, 1.8,
            FreeCAD.Vector(3.9 + col*8, 3.9 + row*8, 9.6)
        )
        brick = brick.fuse(stud)
Part.show(brick)

代码解读

底座makeBox(31.8, 15.8, 9.6)建立2×4积木主体，三个参数分别是长、宽、高。
循环次数外层row取0、1，共2行；内层col取0、1、2、3，共4列，因此循环体执行2×4=8次。
阵列坐标3.9 + col*8和3.9 + row*8把列、行编号换算为圆柱中心坐标，相邻凸点中心距8mm。
创建与合并makeCylinder(2.45,1.8,...)生成半径2.45mm、高1.8mm的凸点；每次用brick.fuse(stud)与当前主体做布尔并。
运行结果：生成31.8×15.8×11.4mm的积木上半部，顶部有2行×4列共8个凸点。
易错点：for行末必须有冒号，循环体必须统一缩进；漏写brick =会导致合并结果没有保存。底部空腔和3根加强管在第9课继续完成。
