📦 Part.makeBox()

makeBox(长, 宽, 高) 创建立方体。

三个参数分别是X、Y、Z方向的尺寸，单位mm。

如 Part.makeBox(60, 18, 3) 创建一个60×18×3mm的薄片。

🥫 Part.makeCylinder()

makeCylinder(半径, 高度, 圆心位置) 创建圆柱。

如 Part.makeCylinder(15, 40, FreeCAD.Vector(0,0,0)) 创建R15高40的圆柱。

👁️ Part.show()

Part.show(几何体) 把几何体显示在3D视图中。

创建几何体后必须show才能看到。

# 实践作业2：参数化桌面笔筒
import FreeCAD
import Part

outer_R = 28
wall_T = 3
height = 80
bottom_T = 3
outer = Part.makeCylinder(outer_R, height)
inner = Part.makeCylinder(outer_R-wall_T, height-bottom_T,
                          FreeCAD.Vector(0, 0, bottom_T))
pen_holder = outer.cut(inner)
Part.show(pen_holder)

代码解读

  1. outer_R、wall_T、height、bottom_T集中保存外半径、壁厚、总高和底厚；修改变量即可整体改尺寸。
  2. outer是半径28mm、高80mm的完整外圆柱。
  3. inner半径为outer_R-wall_T = 25mm，高度为height-bottom_T = 77mm。
  4. FreeCAD.Vector(0,0,bottom_T)把内圆柱向上移动3mm，让底部保留3mm实体。
  5. outer.cut(inner)用布尔差从外圆柱中减去内圆柱，得到开口向上的笔筒；Part.show()负责显示。
运行结果：生成外径56mm、高80mm、侧壁3mm、底厚3mm的中空圆柱基础版。实践作业2再把圆形截面升级为十二边形，并用上下轮廓放样形成轻微外扩。
易错点：wall_T必须小于outer_R，bottom_T必须小于height；若内圆柱没有上移，底部会被完全挖穿。
