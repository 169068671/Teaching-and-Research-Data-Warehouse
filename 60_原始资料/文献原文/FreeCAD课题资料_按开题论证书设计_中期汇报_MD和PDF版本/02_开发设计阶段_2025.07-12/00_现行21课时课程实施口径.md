# 现行21课时课程实施口径

> [!important] 使用范围
> 本文件从“新网站”和“新PPT”提取现行课堂执行口径。课题名称、研究目标、研究计划和成果要求仍以开题论证书为依据；涉及课时、模块内容、作品、软件工作台、教学顺序和评价时，以本文件为准。

## 一、课程基本口径

- 课程名称：代码造物——STEAM理念下基于编程建模的高中3D打印校本课程
- 课题名称：STEAM理念下基于编程建模的高中3D打印校本课程的开发与研究
- 课题编号：2024B-178
- 承担单位：江苏省东台中学
- 主持人：王华军、吴海燕
- 总课时：21课时
- 单课时：45分钟
- 模块结构：六模块，2+3+4+4+4+4
- 建模软件：FreeCAD
- 装配工具：FreeCAD原生Assembly工作台
- 有限元：FreeCAD FEM + CalculiX
- 切片软件：Ultimaker Cura
- 学习主线：设计—编码—验证—打印—迭代—展示

## 二、六模块与21课时

| 模块 | 课时 | 课题 | 主要成果 |
|---|---:|---|---|
| 模块一：3D打印新视界与STEAM启蒙 | 1—2 | 3D打印与STEAM启蒙；FreeCAD初体验与安全规范 | 认识增材制造、STEAM、FreeCAD界面和安全规则 |
| 模块二：手动建模基础与实践 | 3—5 | 界面与草图；几何/尺寸约束；拉伸与实践项目1 | 实践作业1：个性化钥匙扣 |
| 模块三：编程建模入门与逻辑构建 | 6—9 | Python基础；参数化几何体与笔筒；循环与函数；调试与打印检查 | 实践作业2：参数化笔筒；实践作业3：2×4积木块 |
| 模块四：结构设计与原生装配 | 10—13 | 手机支架需求与参数；建模与验证；储物盒槽口与装配；原生装配与运动验证 | 实践作业4：手机支架；实践作业5：带盖储物盒 |
| 模块五：桥梁跨学科项目、有限元与打印验证 | 14—17 | 正弦拱桁架桥；FreeCAD FEM；切片与支撑；打印与承重试验 | 桥梁“模型—仿真—打印—试验”证据链 |
| 模块六：综合STEAM项目设计与成果展示 | 18—21 | 选题与方案；建模与迭代；切片打印与证据文档；并行展评与反思 | 结课综合项目 |

## 三、学生成果与评价

学生正式计分成果共6项：

1. 个性化钥匙扣
2. 参数化桌面笔筒
3. 乐高式2×4积木块
4. 多功能手机支架
5. 带盖储物盒
6. 结课综合项目

模块五桥梁项目是跨学科工程验证任务，形成函数、模型、FEM、切片、打印和承重数据证据链；除非评价方案另行正式修订，不把它增列为第7件学生计分作品。

评价口径：

- 5项实践作业合计占60%：作业1—4取均分计30%，作业5计20%，过程性学习计10%。
- 结课综合项目占40%。
- 结课综合项目提交：方案书、FCStd源文件、STL、打印实物或有效打印证据、90秒陈述提纲、项目证据卡和反思。

## 四、STEAM融合口径

STEAM不是五项标签的简单叠加。每个项目只说明真实发生的融合点：

| 项目 | 主要融合点 |
|---|---|
| 钥匙扣 | T技术 + A艺术 |
| 笔筒 | T技术 + M数学 |
| 2×4积木块 | T技术 + M数学 |
| 手机支架 | T技术 + E工程 + M数学 |
| 带盖储物盒 | T技术 + E工程 + M数学 |
| 正弦拱桁架桥 | S科学 + T技术 + E工程 + M数学 |
| 结课综合项目 | 按自主选题说明实际使用到的领域 |
