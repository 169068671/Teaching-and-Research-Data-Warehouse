## 抽样方案

- **抽样方法**：随机抽样（Python `random.sample`，固定种子 `20260725`，可复现）
- **抽样规模**：每班 3 人，共 6 人
- **覆盖原则**：两班各抽 3 人，编号随机分散，不连续

## 抽样可复现性

抽样使用 Python 固定随机种子，可在任何时候重新运行验证：

```python
import random
random.seed(20260725)
class1 = [f"A{n:02d}" for n in range(1, 31)]
class2 = [f"B{n:02d}" for n in range(1, 31)]
sample1 = sorted(random.sample(class1, 3))  # ['A09', 'A23', 'A26']
sample2 = sorted(random.sample(class2, 3))  # ['B01', 'B05', 'B20']
```
