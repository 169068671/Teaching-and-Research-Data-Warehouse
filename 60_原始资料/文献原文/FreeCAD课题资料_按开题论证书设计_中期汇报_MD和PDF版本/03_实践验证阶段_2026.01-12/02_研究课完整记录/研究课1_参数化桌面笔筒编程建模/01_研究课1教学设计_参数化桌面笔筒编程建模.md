## 二、教学目标

1. 能在FreeCAD Python控制台中正确使用变量、注释、`print()`以及`import FreeCAD`、`import Part`。
2. 能用`Part.makeCylinder()`创建外圆柱和内圆柱，理解半径、高度与起点坐标三个关键参数。
3. 能用`outer.cut(inner)`形成有底内腔，说明内圆柱上移`bottom_T`后保留底厚的原因。
4. 能修改外半径、壁厚、总高和底厚，完成基本参数检查并按规范保存FCStd源文件。

## 五、核心代码与解释

```text
import FreeCAD
import Part

outer_R = 28
wall_T = 3
height = 80
bottom_T = 3

outer = Part.makeCylinder(outer_R, height)
inner = Part.makeCylinder(
    outer_R - wall_T,
    height - bottom_T,
    FreeCAD.Vector(0, 0, bottom_T)
)
pen_holder = outer.cut(inner)
Part.show(pen_holder)

print("外径：", outer_R * 2, "mm")
print("侧壁：", wall_T, "mm")
print("底厚：", bottom_T, "mm")
print("几何有效：", pen_holder.isValid())
```

1. `import FreeCAD`用于调用`FreeCAD.Vector()`坐标对象；`import Part`用于创建和运算实体几何。
2. `outer_R`、`wall_T`、`height`、`bottom_T`分别保存外半径、壁厚、总高和底厚，集中修改变量即可改变模型。
3. `Part.makeCylinder(outer_R, height)`创建半径28mm、高80mm的完整外圆柱。
4. 内圆柱半径为`outer_R-wall_T=25mm`，因此侧壁厚度为3mm；内圆柱高度为`height-bottom_T=77mm`。
5. `FreeCAD.Vector(0,0,bottom_T)`将内圆柱沿Z轴上移3mm，使布尔差不会挖穿底部。
6. `outer.cut(inner)`从外圆柱中减去内圆柱，得到外径56mm、高80mm、侧壁3mm、底厚3mm的开口笔筒。
7. `Part.show()`把运算结果显示在三维视图中；`print()`输出尺寸和有效性，便于核验和调试。
8. 参数必须满足`0<wall_T<outer_R`、`0<bottom_T<height`，否则会出现内半径无效或底部被挖穿等问题。

## 六、教学过程

| 环节 | 时间 | 教师活动 | 学生活动 | 形成证据 |

## 九、安全要求

1. 本课以数字建模为主，不安排学生触碰运行中的3D打印机。
2. 学生不得删除或覆盖他人源文件，修改参数前先保存个人副本。
3. 导出STL不等于可直接打印；后续打印前还需检查壁厚、底厚、尺度和设备安全。
