# FreeCAD专项测评学生访谈提纲

## 适用范围

- 访谈1：2025-11-22 选修一班（A09、A23、A26），模块三课后
- 访谈2：2026-03-28 选修二班（B01、B05、B20），模块五课后

## 访谈伦理

1. 访谈全程不记录学生姓名，只使用匿名编号
2. 匿名编号与学生身份的对应表由学校单独保管
3. 访谈录音（如有）仅供转录使用，转录完成后销毁
4. 访谈内容仅用于课题研究，不作为学生评价依据
5. 访谈地点须避开其他学生，保护隐私

## 访谈1提纲（模块三：草图与拉伸建模）

1. 你觉得FreeCAD跟以前用过的其他画图软件（如画图、PS）最大的区别是什么？
2. 在画草图的时候，几何约束和尺寸约束你是怎么理解的？能不能举个例子？
3. 做笔筒的时候，从草图到拉伸，你脑子里是怎么想的？有没有哪一步卡住？
4. 改一个参数模型就跟着变，这种"参数化"对你来说意味着什么？
5. 你觉得这节课最难的地方是什么？最有趣的地方是什么？
6. 如果让你自己设计一个小物件，你会选什么？为什么？

## 访谈2提纲（模块五：装配与切片打印）

1. 把多个零件装配到一起，和之前画一个零件，你的思维过程有什么不一样？
2. 同轴、面对面、点对点这三类约束，你最常用的是哪个？为什么？
3. 导出STL和切片的时候，层高、填充、支撑这几个参数你是怎么选的？
4. 看到自己的模型被打印出来，你的感受是什么？实物和你想象的有没有差别？
5. 你觉得"数字模型"和"实物"之间的距离，主要差在哪里？
6. 学完装配和打印，你对"工程师是怎么工作的"有没有新的认识？

## 访谈记录要求

1. 访谈人逐题提问，记录人逐字记录学生原话（可借助录音转录）
2. 每位学生6个问题全部作答，不跳题
3. 访谈结束后填写小结：共性认识、个体差异、对课程改进的启示
4. 记录入档至 `03_实践验证阶段_2026.01-12/02_研究课完整记录/过程性材料模板/04_学生访谈记录_第1份.md` 和 `_第2份.md`

## 抽样方案

- 抽样方法：随机抽样（Python `random.sample`，固定种子 20260725，可复现）
- 抽样规模：每班3人，共6人
- 选修一班：A09、A23、A26
- 选修二班：B01、B05、B20
- 两份访谈的匿名编号不重复
