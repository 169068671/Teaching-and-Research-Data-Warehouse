零、单元概述

本单元为"生态鱼缸的设计与制作"项目的起始单元，在4单元16-20课时的项目序列中承担"结构奠基"的关键角色。以"结构"大概念为统领，围绕鱼缸缸体（5块玻璃壳体结构）与铝型材支架（4立柱+8梁框架结构）的设计制作展开，引导学生从真实工程需求出发，认知结构类型、分析受力特点、完成结构选型与建模验证。

核心概念链：结构（承重与稳定）→ 流程（造景工序时序）→ 系统（生态循环关联）→ 控制（温控反馈闭环）。本单元为链条起点，结构是生态鱼缸的"骨骼"。

一、教材分析

本单元教学内容源自《普通高中技术与工程课程标准（2017年版2025年修订）》附录2案例2，隶属必修模块2"技术与工程设计2"。结构是技术设计的物质基础，鱼缸作为承装水体和生物的容器，其缸体结构承受水压、支架结构承受缸体及水体总重，是结构概念学习的绝佳载体。

本单元配套的FreeCAD数字模型包含缸体5块玻璃、铝型材支架（4立柱+8梁）、中层隔板等29个部件，缸体尺寸400×250×300mm，支架尺寸420×270×500mm。学生将在真实项目中认知结构类型（实体结构、框架结构、壳体结构）、理解结构稳定性与强度的决定因素，并将受力分析与材料选择落实到实际产品上。

本单元与后续三个单元存在内在贯通：确定的缸体结构尺寸与支架承载力，为流程单元造景工序提供物理空间约束，为系统单元过滤循环管路安装提供结构基础，更为控制单元传感器与加热器布置提供安装平台。结构设计先行，体现了"大概念贯通式项目设计"中从物质载体到功能实现的螺旋式上升逻辑。

二、学情分析

本单元授课对象为高一年级学生，学生在初中物理中已学习过力的基本概念和压强知识，对"受力""承重"有初步认识，但缺乏对结构类型与结构稳定性的系统认知，难以将力学知识迁移到工程结构设计中。

学生在生活中接触过各类容器和支架，对鱼缸有一定直观经验，但对于"缸体壁厚如何决定""支架为何采用特定构型"等问题缺乏深入思考。部分学生具有初步的三维建模兴趣，但多数未接触过FreeCAD等工程建模工具。学生对AI工具（如大语言模型）有使用热情，但尚需引导其将AI作为工程分析助手而非简单问答工具使用。

三、教学目标（五维核心素养）

依据技术与工程课程核心素养五维框架，设定如下教学目标：

技术意识

通过鱼缸结构实例分析，体会结构设计在工程产品中的基础性作用，形成"结构决定功能实现"的技术意识，能从结构视角审视生活中的容器与支架产品。

工程思维

运用受力分析方法，识别鱼缸缸体（壳体结构承受水压）与支架（框架结构承受总重）的主要受力形式，理解结构稳定性与强度的决定因素，能进行基本的结构选型与尺寸估算。

创新设计

能根据鱼缸使用需求，提出至少两种缸体材料方案和支架结构方案，借助AI工具进行参数对比，运用"结构稳定五维评估器"进行多维度评价。

图样表达

能使用FreeCAD建立鱼缸缸体与支架的三维模型，表达结构设计意图，能绘制结构受力分析简图，规范标注尺寸与材料信息。

物化能力

能根据设计方案选择合适材料，完成缸体粘接和支架组装，通过注水承重测试验证结构设计的可靠性，在制作过程中体现工匠精神。

五、教学策略与方法

5.1 总体策略

采用"大概念贯通式项目学习法"，以"为生态鱼缸设计缸体与支架"为驱动任务，将结构概念学习嵌入真实工程实践。遵循"认知—分析—设计—制作—测试—反思"的工程思维路径，4课时形成完整的学习闭环。教学过程中融合AI智能工具辅助决策和FreeCAD工程建模分析，实现"手脑机"协同的技术学习新形态。

5.2 教学方法

  • 情境驱动法：以真实鱼缸选购困境导入，激发结构设计需求
  • 探究实验法：通过纸片承重、三角形框架稳定性等小实验建立结构直觉
  • AI辅助分析法：运用AI作为结构参数优化助手，辅助多方案决策
  • 建模分析法：运用FreeCAD三维模型，将抽象受力可视化
  • 制作测试法：实物制作并注水测试，验证设计可靠性

5.3 原创教学工具

结构稳定五维评估器

本工具为本单元原创设计，用于引导学生从承重能力、稳定性、耐久性、美观性、成本五个维度对结构方案进行量化评估。每个维度采用1-5分制评分，并设置权重系数，最终计算加权综合得分，辅助学生进行方案优选决策。

评估维度 权重 评分标准（5分制） 考察要点
承重能力 0.30 1分（极弱）—5分（远超需求） 最大承载、安全系数、破坏模式
稳定性 0.25 1分（易倾覆）—5分（抗侧翻） 重心高度、支撑面积、抗倾覆
耐久性 0.20 1分（短期）—5分（长期耐久） 材料老化、防水性、维护周期
美观性 0.15 1分（粗糙）—5分（精致） 外观质感、工艺细节、整体协调
成本 0.10 1分（昂贵）—5分（经济） 材料费、加工费、维护成本

综合得分 = Σ（维度得分 × 权重），满分5.0分。建议3.5分以上方案方可采用。

六、教学过程（4课时）

本单元教学过程共4课时，以时间轴形式呈现完整教学流程。

课时1 · 第1-15分钟

环节一：情境导入——鱼缸选购的"结构困境"

教师活动：展示三款不同材质和结构的鱼缸图片（亚克力一体缸、玻璃拼接缸、钢化玻璃+铝合金支架缸），讲述情境故事："小明想买一个生态鱼缸，网店客服推荐了三种方案，价格从200元到800元不等，小明不知道该选哪种……"

学生活动：观察三款鱼缸的结构差异，小组讨论："为什么不同结构方案的鱼缸价格差异这么大？结构差异对鱼缸使用有什么影响？"

设计意图：以真实选购情境激发学生对结构差异的觉察，引出"结构类型"与"结构性能"的探究需求。

课时1 · 第16-40分钟

环节二：概念建构——结构类型与受力认知

教师活动：结合实物与图片，讲解三类基本结构：

  • 实体结构：以自身实心形体承受载荷（如砖墙、堤坝），鱼缸中的底座实体垫块
  • 框架结构：由杆件通过连接组成骨架承受载荷（如房屋框架、桥梁桁架），鱼缸铝型材支架（4立柱+8梁）
  • 壳体结构：由薄壁曲面承受载荷（如鸡蛋壳、头盔），鱼缸缸体5块玻璃壁面

探究实验：分发A4纸和吸管，学生分组实验：

  • 实验A：平铺纸片 vs 折成W型纸片承重对比——理解形状对强度的影响
  • 实验B：三角形吸管框架 vs 四边形吸管框架按压对比——理解三角形的稳定性

学生活动：记录实验现象，归纳"结构形状与连接方式决定结构稳定性和强度"的核心规律。将鱼缸结构进行归类：缸体=壳体结构，支架=框架结构，底座垫块=实体结构。

课时1 · 第41-45分钟

环节二续：结构受力简图绘制

教师引导学生绘制鱼缸结构受力简图，标注水体对缸体壁面的侧向水压（P = ρgh，与深度成正比，底部压力最大），以及缸体+水体总重通过支架4根立柱传递到地面的受力路径。

FreeCAD模型导入：教师展示已建好的生态鱼缸三维模型（EcoFishTank），引导学生观察模型中缸体5块玻璃的拼合方式和铝型材支架的杆件连接关系，建立空间认知。

模型参数：缸体400×250×300mm（5块5mm厚玻璃），支架420×270×500mm（4根立柱+8根横梁，20×20mm铝型材）。

布置课后任务：测量家中鱼缸或水缸的尺寸，估算满水总重量。

课时2 · 第1-20分钟

环节三：设计实践（一）——缸体材料选择与AI辅助方案对比

任务驱动："为400×250×300mm的生态鱼缸选择缸体材料，需承受约30升水的压力。"

教师活动：介绍常见缸体材料：普通玻璃、钢化玻璃、亚克力（PMMA），讲解各材料的基本力学特性和加工方式。

AI应用任务：教师示范如何使用AI助手进行结构参数优化分析。

提示词示范："请帮我对比普通玻璃、钢化玻璃、亚克力三种材料用作400×250×300mm鱼缸缸体的性能，从抗拉强度、抗冲击性、透光率、耐候性、加工难度、单位成本六个维度生成对比表格，并根据水深300mm计算底部最大水压，给出推荐壁厚建议。"

学生活动：各小组向AI输入不同的材料对比需求，获取AI生成的材料性能对比表，并对AI输出结果进行批判性审查——核实数据是否合理、建议是否安全。

教师引导：提醒学生AI输出可能存在数据偏差，需与课本数据和厂家技术参数交叉验证。引导学生关注安全系数——鱼缸壁厚通常需2-3倍安全余量。底部最大水压 P = 1000×9.8×0.3 = 2940 Pa ≈ 2.94 kPa。

成果产出：各小组完成《缸体材料选择方案书》，包含AI对比表、小组验证结论和最终选材决定。

课时2 · 第21-45分钟

环节三：设计实践（二）——缸体尺寸计算与五维评估

教师活动：讲解缸体尺寸计算方法：

  • 水体体积计算：V = 长 × 宽 × 高（水位高度）= 0.4×0.25×0.3 = 0.03m³ = 30升 = 30kg
  • 缸体壁面水压估算：底部最大压强 P = ρgh = 1000×9.8×0.3 = 2940 Pa
  • 壁厚选择：根据材料许用应力与安全系数确定（安全系数取2-3）
  • 总重量估算：缸体自重（约6kg）+ 水重（30kg）+ 底砂/造景重量（约9kg）≈ 45kg

学生活动：各小组根据选定材料和目标尺寸进行定量计算，填写缸体尺寸计算单。

结构稳定五维评估器——应用实践

各小组运用"结构稳定五维评估器"对亚克力缸、普通玻璃缸、钢化玻璃缸三种方案进行评分：

  • 承重能力（0.30）：评估材料抗拉强度与壁厚是否满足水压要求
  • 稳定性（0.25）：评估缸体重心、底面支撑面积与抗侧翻能力
  • 耐久性（0.20）：评估材料耐水性、抗老化、黄变风险
  • 美观性（0.15）：评估透光率、边缘处理质感、整体视觉效果
  • 成本（0.10）：评估材料费、加工费的综合经济性

计算加权综合得分，选择最优方案。要求3.5分以上方案方可进入制作环节。

课时3 · 第1-25分钟

环节三：设计实践（三）——支架结构设计与FreeCAD模型分析

任务驱动："为选定缸体设计配套支架，需承受缸体+水+造景总重（约45kg），保证长期稳定不变形。"

教师活动：讲解框架结构设计要点：杆件截面选择（方管vs角铁）、节点连接方式（角码/螺栓）、重心与支撑面关系。

FreeCAD模型分析任务：教师展示已建好的支架模型，引导学生分析铝型材支架的结构特点。

分析要点：

  1. 观察支架4根立柱（420mm铝型材，截面20×20×2mm）的分布——四角支撑，均匀承载
  2. 观察8根横梁（4根顶部+4根中部）构成的两层框架——中层横梁为中层隔板提供支撑
  3. 分析支架与缸体的空间关系：支架420×270mm略大于缸体400×250mm，缸体嵌入框架内部
  4. 在FreeCAD中切换不同视角（正视图、俯视图、等轴测视图），观察支架各杆件的空间连接关系
  5. 使用剖面工具截取支架中部截面，观察4立柱+4横梁的闭合框架结构

学生活动：各小组在FreeCAD中打开模型，尝试不同的观察视角，绘制支架结构三视图，标注杆件尺寸和连接方式。讨论：支架为何需要两层横梁？中层横梁有何功能？

课时3 · 第26-45分钟

环节三：设计实践（四）——缸体与支架受力分析

FreeCAD受力分析任务：基于模型进行缸体壳体与支架框架的受力分析。

缸体受力分析（壳体结构）：

  1. 在FreeCAD中单独显示缸体5块玻璃，隐藏其他部件
  2. 分析底板受力：承受水体重力（30kg）+底砂重力（约9kg），均布载荷约3.9kPa
  3. 分析侧壁受力：承受侧向水压，P=ρgh，底部最大2.94kPa，顶部为0，呈三角形分布
  4. 分析前后壁与左右壁的差异：长边壁面（400mm）承受总压力大于短边壁面（250mm）
  5. 引导学生理解：缸体越深，底部水压越大，壁厚需求越高

支架受力分析（框架结构）：

  1. 在FreeCAD中单独显示铝型材支架，隐藏缸体
  2. 分析受力路径：缸体+水总重（约45kg=441N）→ 顶部4根横梁 → 4根立柱 → 地面
  3. 每根立柱承受约110N轴向压力，评估20×20×2mm铝型材的承压能力
  4. 分析支架整体稳定性：支撑面积420×270mm，重心高度约250mm，抗倾覆能力评估
  5. 讨论：若支架仅有4立柱+4顶梁（无中层梁），稳定性如何变化？中层梁的作用是什么？

学生活动：各小组完成受力分析，填写《缸体与支架受力分析报告》。运用"结构稳定五维评估器"对最终支架方案评分。

设计意图：通过FreeCAD模型的分层显示和剖面分析，将抽象的力学分析转化为直观的空间可视化，让学生体验工程师"建模-分析-优化"的完整工作流。

课时4 · 第1-20分钟

环节四：制作测试（一）——缸体制作与支架组装

教师活动：讲解缸体制作工艺与安全注意事项：

  • 玻璃缸：玻璃切割（由专业店家完成）→ 边缘打磨 → 硅酮密封胶粘接 → 固化24h
  • 亚克力缸：亚克力板切割 → 边缘抛光 → 氯仿/专用胶水粘接 → 固化
  • 支架组装：铝型材切割 → 角码连接/螺栓紧固 → 水平校准

安全提示：玻璃边缘锋利需佩戴手套；密封胶有气味需通风操作；工具使用需遵守操作规程。

学生活动：各小组按设计图纸进行缸体粘接（使用预制切割好的板材）和支架组装。教师巡回指导，重点检查粘接密封性和支架节点紧固度。

制作过程融入工匠精神教育：密封胶涂抹均匀无气泡，支架螺栓拧紧力矩一致，细节决定成败。
课时4 · 第21-40分钟

环节四：制作测试（二）——注水承重测试与结构验证

测试方案：分阶段注水测试——先注水1/3高度观察30分钟，再注水2/3观察30分钟，最后满水观察1小时。

观察记录要点：

  • 缸体：粘接处有无渗漏？壁面有无明显变形？有无异常声响？
  • 支架：四脚是否均匀着地？有无倾斜？连接节点有无松动？
  • 整体：结构有无共振？放置面是否水平？

学生活动：各小组执行注水测试，填写《结构测试记录表》，记录测试现象与数据。对出现问题的方案进行现场诊断和加固修复。

课时4 · 第41-45分钟

环节五：总结反思——结构设计复盘与项目衔接

教师活动：组织全班进行结构设计成果展示与互评。引导总结：

  • 结构类型选择如何影响产品性能？
  • 受力分析在设计决策中发挥了什么作用？
  • AI参数对比和FreeCAD模型分析分别带来了哪些帮助？

项目衔接预告："缸体和支架已经就位，接下来我们面临一个新的挑战——如何将底砂、水草、沉木等素材有序布置到鱼缸中？这就是我们下一单元要学习的'流程设计'。"——自然过渡到流程单元。

七、评价方式

本单元采用多元过程性评价，融合教师评价、同伴互评和自我反思三个维度，贯穿教学全过程。

八、板书设计

结构单元 缸体与支架结构设计
一、结构类型
　　实体结构 → 底座垫块
　　框架结构 → 铝型材支架（4立柱+8梁）
　　壳体结构 → 缸体壁面（5块玻璃）
二、缸体设计
　　材料：普通玻璃 / 钢化玻璃 / 亚克力
　　水压：P = ρgh （底部最大 2.94kPa）
　　壁厚：安全系数 × 计算厚度
　　AI参数对比 → 五维评估 → 选材决策
三、支架设计
　　构型：4立柱+8横梁 铝型材框架
　　FreeCAD模型 → 受力路径分析
　　传力：缸体→顶梁→立柱→地面
四、制作测试
　　粘接组装 → 分级注水 → 观察30min
　　验证：密封性 + 稳定性 + 承重性
【贯通】结构 → 流程 → 系统 → 控制
【工具】结构稳定五维评估器

九、单元作品要求

作品一：鱼缸缸体与支架结构设计报告（小组）

各小组提交完整的结构设计报告，须包含以下内容：

  • 结构选型方案：缸体材料选择方案书（含AI对比表、批判审查记录、五维评估评分表）
  • 尺寸计算单：水体体积、水压、壁厚、总重量的定量计算过程
  • FreeCAD模型分析：缸体壳体受力分析图、支架框架传力路径图、三视图（正视图/俯视图/侧视图）
  • 制作与测试记录：制作工艺流程记录、分级注水测试记录表、问题诊断与修复记录

作品二：鱼缸缸体与支架实物（小组）

各小组完成缸体粘接和支架组装的实物作品，需满足：

  • 缸体尺寸符合设计要求，粘接密封无渗漏
  • 支架结构稳固，四脚均匀着地，节点紧固
  • 通过分级注水承重测试（满水1小时无渗漏、无变形）
  • 外观整洁，体现工匠精神
作品交付节点：课时4结束时提交设计报告和实物作品，作为本单元终结性评价依据，同时实物作品将作为后续流程单元、系统单元、控制单元的项目载体持续使用。
