零、单元概述

本单元为"生态鱼缸的设计与制作"项目的第三单元，在4单元16-20课时的项目序列中承担"系统集成"的关键角色。以"系统"大概念为统领，围绕鱼缸生态循环系统设计展开，引导学生从造景已完成的真实情境出发，认知系统与子系统的构成、理解系统关联与整体性思想，并通过过滤、增氧、温控三大子系统的关联设计，体会系统设计在工程实践中的价值。

一、教材分析

本单元教学内容源自《普通高中技术与工程课程标准（2017年版2025年修订）》附录2案例2，隶属必修模块2"技术与工程设计2"。系统是由相互关联的若干组成部分构成的具有特定功能的有机整体，任何工程产品都可视为系统。鱼缸生态循环系统由过滤子系统、增氧子系统、温控子系统三大功能模块构成，三者通过水流、能量、信息的传递相互关联，共同维持鱼缸生态平衡，是系统概念学习的理想载体。

本单元承接结构单元的缸体支架成果和流程单元的造景成果。FreeCAD数字模型包含过滤箱、水泵、输水管、温度传感器、LED灯条、中层隔板等部件，可清晰展示各子系统在鱼缸整体中的空间位置和连接关系。学生将在真实项目中认知系统的构成（子系统、要素、关联、边界、环境）、理解系统的整体性与相关性，并通过子系统关联设计体会"1+1>2"的系统思想。

本单元与项目其他单元存在内在贯通：结构单元的支架中层隔板为过滤箱提供安装平台；流程单元的造景时序为管路安装预留工序窗口；系统单元确定的子系统布局为控制单元温控传感器的精确布置和控制回路设计提供物理基础。系统集成承前启后，体现了"大概念贯通式项目设计"中从有序运行到智能反馈的递进逻辑。

二、学情分析

本单元授课对象为高一年级学生，学生在生活中接触过各类系统（如自来水系统、供暖系统），对"配套""整体"有朴素认识，但缺乏对系统、子系统、关联、边界等系统化概念认知，难以将日常经验提炼为工程化的系统设计语言。

学生在结构单元和流程单元中已掌握鱼缸的结构特征和造景流程，对鱼缸作为"容器"有较深认知，但对于"鱼缸如何成为自我维持的生态系统""各功能模块如何协同"等问题缺乏系统思考。部分学生具有初步的系统图绘制经验，但多数未接触过系统关联分析方法。学生对AI工具（如大语言模型）有使用热情，但尚需引导其将AI作为生态平衡预测助手而非简单问答工具使用。

三、教学目标（五维核心素养）

依据技术与工程课程核心素养五维框架，设定如下教学目标：

技术意识

通过鱼缸生态循环系统实例分析，体会系统设计在工程产品中的整体性作用，形成"系统大于部分之和"的技术意识，能从系统视角审视生活中的多功能产品。

工程思维

运用系统分析方法，识别鱼缸生态系统的子系统构成与关联关系，理解整体性、相关性、动态性等系统基本特性，能进行基本的子系统划分与关联分析。

创新设计

能根据鱼缸生态平衡需求，提出至少两种子系统布局方案，借助AI工具进行生态平衡预测，运用"系统关联图谱"进行多维度评价，体现整体优化的设计取向。

图样表达

能使用规范符号绘制系统关联图，表达子系统的构成、关联与边界，能借助FreeCAD模型展示各子系统的空间位置和连接关系。

物化能力

能根据系统设计方案组装过滤、增氧、温控子系统并完成联调，通过运行测试验证系统整体的协同性，在制作过程中体现规范操作与工匠精神。

五、教学策略与方法

5.1 总体策略

采用"大概念贯通式项目学习法"，以"为已完成造景的鱼缸设计生态循环系统"为驱动任务，将系统概念学习嵌入真实工程实践。遵循"认知—分析—设计—集成—测试—反思"的工程思维路径，4课时形成完整的学习闭环。教学过程中融合AI智能工具辅助生态平衡预测和FreeCAD工程模型空间关系可视化，实现"手脑机"协同的技术学习新形态。

5.2 教学方法

  • 情境对比法：以有循环系统与无循环系统的鱼缸对比导入，激发系统设计的必要性认识
  • 图样表达法：通过系统关联图的规范绘制，建立系统的工程化表达语言
  • AI辅助预测法：运用AI作为生态平衡预测助手，辅助多方案生态效果预测与决策
  • 建模可视化法：运用FreeCAD模型的分层显示，将子系统空间关系和连接可视化
  • 集成测试法：组装子系统并联调，通过运行测试验证系统整体协同性

5.3 原创教学工具

系统关联图谱

本工具为本单元原创设计，用于引导学生从功能完整性、关联紧密度、协同效率、可靠性、可维护性五个维度对系统方案进行量化评估。每个维度采用1-5分制评分，并设置权重系数，最终计算加权综合得分，辅助学生进行系统方案优选决策。

评估维度 权重 评分标准（5分制） 考察要点
功能完整性 0.30 1分（功能缺失）—5分（功能完备） 过滤/增氧/温控三大功能覆盖度
关联紧密度 0.25 1分（松散孤立）—5分（紧密耦合） 子系统间水流/能量/信息传递效率
协同效率 0.20 1分（相互干扰）—5分（协同增效） 整体能效、冗余度、1+1>2效应
可靠性 0.15 1分（易失效）—5分（高可靠） 单点故障影响、容错能力、备份
可维护性 0.10 1分（难维护）—5分（易维护） 部件可达性、清洗/更换便捷度

综合得分 = Σ（维度得分 × 权重），满分5.0分。建议3.5分以上方案方可采用实施。

六、教学过程（4课时）

本单元教学过程共4课时，以时间轴形式呈现完整教学流程。

课时1 · 第1-15分钟

环节一：情境导入——鱼缸生态的"崩溃之困"

教师活动：展示两个鱼缸运行一周后的对比：鱼缸A仅有造景无循环系统，水体浑浊发黄、水草萎蔫、鱼儿浮头喘息；鱼缸B装配了过滤、增氧、温控系统，水体清澈、水草舒展、鱼儿活跃。讲述情境故事："两位同学的鱼缸造景都很美，为什么一周后命运截然不同？"

学生活动：观察两个鱼缸的运行差异，小组讨论："除了造景，鱼缸还需要什么才能长期维持生态？这些功能之间有什么关系？"

设计意图：以正反对比情境激发学生对系统协同的觉察，引出"系统""子系统""关联"的探究需求。

课时1 · 第16-40分钟

环节二：概念建构——系统、子系统与关联

教师活动：结合实物与图片，讲解系统的核心概念：

  • 系统：由相互关联的若干组成部分（要素）构成的具有特定功能的有机整体
  • 子系统：系统中承担特定功能、相对独立的部分，如鱼缸生态系统的过滤子系统、增氧子系统、温控子系统
  • 关联：子系统之间通过物质、能量、信息的传递形成的相互影响关系
  • 系统基本特性：整体性（1+1>2）、相关性（子系统相互影响）、动态性（系统状态随时间变化）

系统图符号讲授：教师讲解系统关联图的基本符号——矩形（子系统/要素）、箭头（关联流向，标注物质/能量/信息）、虚线框（系统边界）。

探究活动：学生分组分析常见生活系统（自来水系统、供暖系统、自行车），用系统图符号绘制简单系统关联图，标注子系统和关联。

学生活动：归纳"子系统协同产生整体功能"这一核心规律：例如过滤子系统净化水质、增氧子系统补充溶解氧，二者通过水流关联共同维持鱼类生存。

课时1 · 第41-45分钟

环节二续：鱼缸生态系统初识与FreeCAD模型导入

教师引导学生初步识别鱼缸生态循环系统的三大子系统及其功能边界。

FreeCAD模型导入：教师展示已建好的生态鱼缸三维模型（EcoFishTank），引导学生观察模型中过滤箱、水泵、输水管、温度传感器、LED灯条等部件的空间分布，建立"系统由空间分布的各子系统构成"的直观认知。

模型参数：过滤箱位于中层隔板，水泵驱动水流循环，输水管连接缸体与过滤箱，温度传感器贴附缸壁，LED灯条位于支架顶部。各部件的空间位置正是子系统功能的物理映射。

布置课后任务：观察家中一项多功能电器，绘制其系统关联图。

课时2 · 第1-20分钟

环节三：设计实践（一）——三大子系统识别与AI生态平衡预测

任务驱动："为已完成造景的400×250×300mm生态鱼缸设计生态循环系统，需维持长期生态平衡。"

教师活动：引导学生识别三大子系统及其功能要素：

  • 过滤子系统：物理过滤（过滤棉拦截残饵粪便）→ 生化过滤（陶瓷环培养硝化菌分解氨氮）→ 水流回流
  • 增氧子系统：水泵跌水增氧 / 气泵气石增氧 → 溶解氧补充 → 满足鱼类与硝化菌呼吸
  • 温控子系统：温度传感器监测 → 加热棒升温 / 风扇降温 → 维持适宜水温（24-28℃）

AI应用任务：教师示范如何使用AI助手进行生态平衡预测。

提示词示范："请帮我预测生态鱼缸的生态平衡状态。鱼缸尺寸400×250×300mm，水量约30升，计划养殖5条小型热带鱼，种植3株水草。配置过滤子系统（过滤棉+陶瓷环）、增氧子系统（水泵跌水）、温控子系统（加热棒+传感器）。请预测：① 氨氮循环能否建立平衡？② 溶解氧是否充足？③ 水温波动范围？④ 三个子系统的关联关系如何？⑤ 给出两种不同的系统配置方案（经济型 vs 高配型）并对比其生态稳定性。"

学生活动：各小组向AI输入不同的系统预测需求，获取AI生成的生态平衡分析表和方案对比，并对AI输出结果进行批判性审查——核查预测是否合理、关联判断是否成立。

教师引导：提醒学生AI可能误判某些关联的紧密度，例如过滤与增氧通过水流强耦合（水泵同时驱动过滤和跌水增氧），而温控相对独立。引导学生关注系统整体性——单子系统最优未必整体最优。

成果产出：各小组完成《生态循环系统初步设计书》，包含子系统识别表、AI预测分析表和小组验证结论。

课时2 · 第21-45分钟

环节三：设计实践（二）——系统关联图绘制与系统关联图谱应用

教师活动：讲解系统关联图绘制规范，示范如何用规范符号表达三大子系统的构成、关联和边界，并标注关联类型（水流/能量/信息）。

学生活动：各小组根据AI预测结果，绘制两种系统方案（经济型、高配型）的系统关联图，标注子系统、关联流向和系统边界。

系统关联图谱——应用实践

各小组运用"系统关联图谱"对经济型方案和高配型方案进行评分：

  • 功能完整性（0.30）：评估三大功能覆盖度（如经济型是否省略温控）
  • 关联紧密度（0.25）：评估子系统耦合度（如水泵是否同时驱动过滤与增氧）
  • 协同效率（0.20）：评估整体能效（如过滤回流水流是否兼作增氧跌水）
  • 可靠性（0.15）：评估单点故障影响（如水泵故障是否导致过滤增氧同时失效）
  • 可维护性（0.10）：评估部件可达性（如过滤棉是否便于清洗更换）

计算加权综合得分，选择最优方案。要求3.5分以上方案方可进入实施环节。

课时3 · 第1-25分钟

环节三：设计实践（三）——FreeCAD模型子系统空间关系可视化

任务驱动："将抽象的子系统关联转化为可视化的空间布局，验证系统方案的可行性。"

教师活动：讲解系统关联与空间布局的对应关系——子系统的关联本质上是部件在鱼缸整体中的空间连接关系。

FreeCAD模型子系统空间分析任务：教师展示已建好的鱼缸模型，引导学生通过模型的分层显示与装配树，理解各子系统的空间位置和连接关系。

分析要点：

  1. 在FreeCAD装配树中识别子系统部件：过滤箱、水泵、输水管（过滤子系统）；水泵/气石（增氧子系统）；温度传感器、加热棒（温控子系统）
  2. 单独显示过滤子系统：观察过滤箱位于中层隔板的位置，分析其利用支架中层空间的合理性
  3. 叠加显示水泵与输水管，观察水流路径：缸体→输水管→过滤箱→水泵→回流缸体，形成闭环
  4. 分析增氧与过滤的耦合：水泵回流水流跌入缸体水面形成跌水增氧，一泵两用体现系统协同
  5. 叠加显示温度传感器，观察其贴附缸壁的位置，分析其监测水温的代表性
  6. 使用剖面工具截取缸体与中层隔板的纵向截面，直观呈现"缸体—输水管—过滤箱—水泵"的空间连接关系

学生活动：各小组在FreeCAD中操作模型，按子系统逐层显示部件，绘制子系统空间布局图，将系统关联图与空间布局图对照。讨论：FreeCAD模型的空间连接如何印证子系统关联？

课时3 · 第26-45分钟

环节三：设计实践（四）——系统关联优化与方案定稿

教师活动：讲解系统优化的核心思想——在保证功能完整的前提下，通过子系统耦合、共享资源、减少冗余来提升协同效率，同时通过冗余备份来降低单点故障风险。

FreeCAD辅助优化任务：基于模型空间关系，分析系统优化机会。

优化分析：

  1. 识别耦合机会：水泵同时驱动过滤水流和跌水增氧，一泵两用提升协同效率
  2. 识别独立模块：温控子系统（加热棒+传感器）相对独立，可单独调试不影响过滤增氧
  3. 识别冗余风险：水泵是单点故障源，一旦失效过滤增氧同时瘫痪——讨论是否需要气泵备份增氧
  4. 识别空间约束：过滤箱体积受中层隔板尺寸限制，影响生化过滤容量
  5. 在FreeCAD中模拟"移除过滤箱"或"移除水泵"的反例，观察系统整体功能如何退化（教师演示反例）

AI应用任务：各小组将优化后的系统方案提交AI进行二次预测。

提示词示范："请帮我评估以下优化后的鱼缸生态循环系统方案：过滤子系统（过滤棉+陶瓷环，过滤箱置于中层隔板）+ 增氧子系统（水泵跌水增氧，与过滤耦合）+ 温控子系统（加热棒+温度传感器，独立模块）。请评估该方案的生态平衡稳定性、子系统关联紧密度、单点故障风险，并给出进一步优化建议。"

学生活动：各小组对比AI建议与自身设计，进行方案定稿，更新系统关联图谱评分。

设计意图：通过FreeCAD模型的空间关系可视化和AI的生态平衡预测双重辅助，让学生体验工程师"建模—分析—优化—定稿"的完整系统设计工作流。

课时4 · 第1-20分钟

环节四：集成测试（一）——子系统组装与联调

教师活动：讲解子系统组装规范与安全注意事项：

  • 过滤子系统：过滤棉铺设→陶瓷环填充→过滤箱就位中层隔板→输水管连接缸体与过滤箱
  • 增氧子系统：水泵安装于过滤箱出水口→调整出水角度形成跌水→检查气石（如有）
  • 温控子系统：加热棒吸附缸体后壁→温度传感器贴附缸体侧壁→连接控制器
  • 系统联调：注水至运行水位→启动水泵→检查水流循环→启动加热棒→监测温度

安全提示：电器设备（水泵、加热棒）通电前确认水中无裸露接头；加热棒必须完全浸水后通电；走线整齐避免水溅。

学生活动：各小组按优化后的系统方案组装三大子系统并联调，记录每个子系统的安装位置、连接方式和联调现象。教师巡回指导，重点检查子系统连接密封性和电气安全。

组装过程融入规范操作教育：管路连接密封无渗漏、电气走线整齐防水、子系统联调循序启动，细节决定系统稳定。
课时4 · 第21-40分钟

环节四：集成测试（二）——系统协同验证与整体评估

评估方案：系统联调后运行观察30分钟，评估系统协同效果。

观察记录要点：

  • 过滤效果：水流是否顺畅循环？过滤箱有无渗漏？水体浑浊度是否下降？
  • 增氧效果：跌水是否形成？水面有无气泡？溶解氧是否提升（可用试纸粗测）？
  • 温控效果：加热棒是否启停？温度是否稳定在设定区间？传感器读数是否准确？
  • 系统协同：三个子系统是否相互干扰？整体运行是否平稳？有无异常噪声？
  • 单点影响：暂停水泵，观察过滤增氧同时失效的后果（教师演示反例）

学生活动：各小组执行系统协同评估，填写《生态系统运行记录表》，记录运行数据与整体评估。对出现问题的子系统进行关联诊断和改进建议。

课时4 · 第41-45分钟

环节五：总结反思——系统设计复盘与项目衔接

教师活动：组织全班进行系统设计成果展示与互评。引导总结：

  • 子系统关联设计如何影响系统整体性能？
  • 系统整体性思想在设计决策中发挥了什么作用？
  • AI生态预测和FreeCAD模型空间可视化分别带来了哪些帮助？

项目衔接预告："生态系统已经运转起来，水质清澈、溶氧充足、温度稳定。但一个新的问题出现了——温度会因昼夜波动、季节变化而偏离设定值，如何让鱼缸自动维持恒温？如何实现远程监控和自动喂食？这就是我们下一单元要学习的'控制设计'。"——自然过渡到控制单元。

七、评价方式

本单元采用多元过程性评价，融合教师评价、同伴互评和自我反思三个维度，贯穿教学全过程。

八、板书设计

系统单元 生态循环系统设计
一、系统概念
　　系统 = 子系统 + 关联 + 边界
　　子系统：过滤 / 增氧 / 温控
　　特性：整体性 / 相关性 / 动态性
二、生态系统设计
　　过滤（物理+生化）↕ 增氧（跌水）↕ 温控（加热+传感）
　　AI生态预测 → 系统关联图谱 → 方案定稿
三、FreeCAD空间可视化
　　过滤箱→中层隔板 / 水泵→耦合 / 传感器→缸壁
　　空间连接 = 系统关联
　　剖面图验证耦合关系
四、集成测试
　　子系统组装 → 联调运行30min
　　验证：过滤效果 + 增氧效果 + 温控效果 + 协同性
【贯通】结构 → 流程 → 系统 → 控制
【工具】系统关联图谱

九、单元作品要求

作品一：鱼缸生态循环系统设计报告（小组）

各小组提交完整的系统设计报告，须包含以下内容：

  • 系统方案设计：生态循环系统初步设计书（含子系统识别表、AI预测分析表、批判审查记录）
  • 系统关联图绘制：经济型方案和高配型方案的规范系统关联图（含子系统、关联流向、边界）
  • FreeCAD模型分析：子系统空间布局图、连接关系剖面截图、空间耦合分析说明
  • 系统关联图谱评分：两方案五维评分表、加权综合得分、定稿方案及优化依据
  • 集成与测试记录：组装记录表、联调运行记录表、协同评估表、问题诊断与改进建议

作品二：鱼缸生态循环系统实物成果（小组）

各小组完成三大子系统组装与联调的实物作品，需满足：

  • 过滤子系统运行顺畅，水体循环无渗漏，浑浊度明显下降
  • 增氧子系统形成跌水，溶解氧达到鱼类生存标准
  • 温控子系统启停正常，温度稳定在设定区间（24-28℃）
  • 三个子系统协同运行无相互干扰，整体平稳
  • 电气走线整齐防水，体现规范操作与工匠精神
作品交付节点：课时4结束时提交设计报告和实物作品，作为本单元终结性评价依据，同时实物作品将作为后续控制单元的项目载体持续使用。
