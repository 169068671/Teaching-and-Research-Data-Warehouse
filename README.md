# 教科研数据仓库

独立 Obsidian 仓库，面向高中技术与工程教师，以真实教学数据为中心组织研究方向、研究主题、参考文献、AI 摘要、政策、同行研究、日常教学、教师反思、数据规划、分析和成果。

打开 Obsidian 后，选择本文件所在文件夹作为仓库，并从 [[00_HOME/教科研数据仓库首页]] 开始。

处理文章、硕博论文、完整课题资料、教案、课件、学习单或其他教学材料时，使用 [[05_工作流/教科研材料数据化分解工作流]]。
