# 标签与字段规范

## 核心字段

| 字段 | 用途 | 示例 |
|---|---|---|
| `title` | 人可读标题 | 项目式学习中的方案决策能力 |
| `record_type` | 唯一主类型 | literature、policy、daily_teaching |
| `status` | 当前状态 | captured、processing、verified、archived |
| `created` | 建立日期 | 2026-07-20 |
| `updated` | 更新日期 | 2026-07-20 |
| `research_theme` | 关联研究主题 | 指向对应的研究主题笔记 |
| `course_module` | 课程模块 | 必修一、必修二、选择性必修 |
| `grade` | 年级 | 高一 |
| `class_code` | 匿名班级代码 | G1-C03 |
| `source` | 来源说明 | DOI、网址、文件或现场观察 |
| `verification_status` | 核验状态 | unverified、verified |
| `sensitivity` | 敏感级别 | public、internal、restricted |
| `tags` | 多维筛选 | `[教科研/文献, 学科/技术与工程]` |

## record_type 受控词表

`research_direction`、`research_theme`、`literature`、`ai_summary`、`policy`、`peer_research`、`teaching_research_activity`、`material_decomposition`、`teaching_material_analysis`、`daily_teaching`、`teaching_reflection`、`student_communication`、`data_plan`、`dataset`、`classroom_observation`、`questionnaire`、`interview`、`student_artifact`、`analysis_memo`、`evidence_chain`、`finding`、`output`。

## 标签体系

- `#教科研/方向`、`#教科研/主题`、`#教科研/文献`、`#教科研/政策`、`#教科研/同行研究`
- `#教学数据/课堂`、`#教学数据/反思`、`#教学数据/学生作品`
- `#教学数据/学生交流`、`#教科研/材料分解`、`#教科研/教学材料`
- `#研究方法/量化`、`#研究方法/质性`、`#研究方法/混合`
- `#数据治理/质量`、`#数据治理/伦理`、`#数据治理/真实性`
- `#学科/技术与工程`、`#学科/工程思维`、`#学科/项目式学习`、`#学科/AI赋能`

> [!tip] 命名规则
> 文件名优先使用 `YYYY-MM-DD_对象_主题`；班级和学生只使用匿名代码。标签用于筛选，具体语义关系使用 Obsidian 双链。
