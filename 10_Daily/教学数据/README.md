# 每日教学数据

每节课或每天一条，使用 [[../../90_模板/每日教学数据模板]]。优先记录能复核的事实：数量、作品、原话、行为、时间、版本和测试结果。

## 最小记录法

只填六项也可以：日期、班级代码、课题、目标、一个关键数据、一个下一步动作。
