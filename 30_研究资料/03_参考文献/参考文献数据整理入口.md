# 参考文献数据整理入口

> [!important] 目标
> 把“收藏了一篇文献”推进到“元数据准确、全文可定位、数据方法可提取、摘要已核验、能够安全引用”的状态。

## 快速开始

1. 将文献 PDF、网页或书目信息放入 [[../../00_Inbox/待分解材料/README|待分解材料]]。
2. 查重后复制 [[../../90_模板/参考文献模板]]，一篇文献一条笔记。
3. 原文附件放入 `60_原始资料/文献原文`，不得覆盖已有版本。
4. 需要 AI 整理时另建 [[../../90_模板/AI摘要核验模板]]，不要覆盖人工文献笔记。
5. 按 [[../../05_工作流/教科研材料数据化分解复核对照材料|复核对照材料]] 核查关键引用和证据位置。

## 文献处理流水线

```mermaid
flowchart LR
    A["文献收件"] --> B["查重"]
    B --> C["元数据核验"]
    C --> D["主题分类"]
    D --> E["数据与方法提取"]
    E --> F["AI摘要与人工核验"]
    F --> G["质量和相关性评价"]
    G --> H["引用与复用"]
```

## 阶段 L1：收件与查重

- 使用 DOI、规范题名、作者和年份组合查重。
- 同一文献不同版本建立版本关系，不重复建立正式笔记。
- 区分预印本、会议版、期刊版、学位论文版和修订版。
- 没有全文时保留书目信息，并标记 `full_text_status: missing`。

## 阶段 L2：元数据核验

至少核验：

- 题名、作者顺序、年份、文献类型和语言。
- 期刊/学校/出版社、卷期、页码。
- DOI、ISBN、CNKI 等稳定标识和官方地址。
- 学位论文的学位类型、授予单位和导师信息（如研究需要）。

> [!warning]
> AI 生成的书目信息只能作为检索线索，必须回到出版方、数据库记录或文献原件核对。

## 阶段 L3：主题与用途分类

- 关联研究方向和研究主题。
- 标记课程模块、学段、研究对象和学科。
- 标记文献角色：理论基础、研究综述、方法依据、工具来源、数据对照、反例或政策依据。
- 标记阅读状态和引用状态。

## 阶段 L4：数据与方法提取

提取研究问题、对象、样本、周期、方法、变量、工具、数据类型、分析方法、核心发现、限制和证据位置。

对于技术与工程研究，重点标记是否包含：

- 设计方案、CAD、模型、原型和学生作品。
- 测试、失败、迭代和优化数据。
- 工程思维、方案决策、协作和技术伦理指标。
- 课堂观察、师生交流、访谈和教师反思。

## 阶段 L5：AI摘要与人工核验

- AI 摘要记录工具、模型、输入范围、提示目的和生成日期。
- 逐项核验研究问题、样本、方法、数字和核心结论。
- 未核验摘要保持 `verification_status: unverified`，不得正式引用。

## 阶段 L6：质量与相关性评价

| 维度 | 评价问题 |
|---|---|
| 来源可信度 | 是否为正式出版、学位论文、权威政策或可核查来源？ |
| 方法透明度 | 样本、工具、数据和分析过程是否说明？ |
| 证据强度 | 结论是否得到数据支持？ |
| 学科相关性 | 与高中技术与工程研究的关系有多直接？ |
| 可复用性 | 工具、指标、任务或设计能否迁移？ |
| 时效性 | 理论和证据是否仍适用于当前政策与教学环境？ |

## 阶段 L7：引用与复用

- 正式写作前再次核验完整引文和具体页码。
- 区分直接引文、转述、二手引用和自己的解释。
- 把文献连接到研究问题、数据规划、方法选择和证据链。
- 标记 `citation_status: cited` 后，登记引用在哪个成果中。

## 完成门槛

- [ ] 已查重并确定主版本。
- [ ] 元数据和稳定标识已经核验。
- [ ] 全文状态、阅读状态和引用状态明确。
- [ ] 研究问题、样本、方法、数据和发现已提取。
- [ ] 核心证据有页码、章节、表号或图号。
- [ ] AI 摘要与人工笔记分开，核验状态准确。
- [ ] 已关联研究方向、主题和使用场景。
- [ ] 未发现编造的作者、题名、年份、DOI、页码或结论。
