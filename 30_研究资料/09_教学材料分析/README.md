# 教学材料数据化分析

本目录用于分析教案、课件、学习单、试卷、评价量规、实验任务书、学生作品范例和课程资源包。

使用 [[../../90_模板/教学材料数据化分解模板]]，按 [[../../05_工作流/教科研材料数据化分解工作流#教学材料专用分支：把“教学设计”转成“可采集数据”|教学材料专用分支]] 执行。

核心原则：教学设计是预设，不是已经发生的课堂事实。分析结果必须进一步转化为课堂观察、学生作品、测试记录、教师教学数据和反思等真实数据采集方案。
