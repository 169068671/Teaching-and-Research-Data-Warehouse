## 核心内容速览

### 2025年修订版主要变化

| 项目 | 内容 |
|------|------|
| 课程名称 | 从"通用技术"改为"技术与工程" |
| 五大核心素养 | 技术意识、工程思维、创新设计、图样表达、物化能力 |
| 工程思维四层次 | 思想和方法的理解 → 系统分析 → 模型认知与建构 → 权衡决策与风险评估 |
| 必修 | 2个模块，3学分，54课时 |
| 选择性必修 | 3个系列，8个模块（从11个精简为8个） |
| 选修 | 6个模块（从4个拓展为6个） |
| 学业质量三段式 | "怎么看"（认知）→ "怎么办"（规划）→ "怎么做"（实践） |
| 三大考试形式 | 纸笔考试、实践操作考试、计算机环境考试 |

## 附录2：教学与评价案例

### 案例1：基于螺旋式上升策略的教学设计——机动车三角警告牌系列技术试验

#### 基本信息

| 项目 | 内容 |
|------|------|
| 课时 | 5课时 |
| 课程模块 | 必修模块1：技术与工程设计1 |
| 核心素养 | 技术意识、物化能力、工程思维 |
| 项目载体 | 机动车三角警告牌 |

#### 教学目标

1. **知识与技能**：掌握三角警告牌的国家标准要求，能够进行尺寸检测和抗风稳定性测试
2. **过程与方法**：经历"技术试验→数据分析→方案优化"的完整工程实践过程
3. **情感态度与价值观**：形成标准意识、安全意识，养成严谨细致的工匠精神

#### 教学过程

| 课时 | 环节 | 教学内容 |
|------|------|---------|
| 第1课时 | 情境导入 | 展示交通事故现场图片，引导学生思考三角警告牌的警示作用；引入国家标准GB/T 19114要求 |
| 第2课时 | 国标研读 | 学生分组研读三角警告牌国家标准，提取关键参数：尺寸、颜色、反光性能、放置距离等 |
| 第3课时 | 分层试验（一） | 尺寸检测：学生使用直尺测量不同三角警告牌的边长、角度，验证是否符合标准要求 |
| 第4课时 | 分层试验（二） | 视辨性测试：制作简易风洞，模拟不同风力条件下三角警告牌的可见距离 |
| 第5课时 | 数据研判与方案优化 | 汇总试验数据，分析不同设计方案优缺点，优化改进；跨国标对比（欧盟EN标准、美国SAE标准） |

#### 教学评价

采用**过程性评价+作品评价**相结合的多元评价方式：

| 评价维度 | 评价内容 | 等级标准 |
|---------|---------|---------|
| 过程性评价 | 试验记录规范性、数据分析能力 | 优秀/良好/合格/待改进 |
| 试验装置评价 | 风洞制作质量、测量工具使用规范性 | 优秀/良好/合格/待改进 |

#### 设计意图

本案例采用"螺旋式上升"策略，通过五个课时的递进活动，使学生经历"认识标准→理解标准→应用标准→超越标准"的认知发展过程，培养技术试验能力和工程思维品质。

### 案例2：贯通大概念的技术与工程设计项目——生态鱼缸的设计与制作

#### 基本信息

| 项目 | 内容 |
|------|------|
| 课时 | 16-20课时（4个单元） |
| 课程模块 | 必修模块2：技术与工程设计2 |
| 核心概念 | 结构、流程、系统、控制 |
| 项目载体 | 生态鱼缸的设计与制作 |

#### 教学目标

1. **知识与技能**：理解结构稳定性、流程时序、系统优化、自动控制的基本原理
2. **过程与方法**：完成从设计→制作→测试→优化的完整工程实践过程
3. **情感态度与价值观**：体验工程实践的复杂性，培养工程思维和团队协作精神

#### 教学过程

| 单元 | 课时 | 核心概念 | 教学内容 |
|------|------|---------|---------|
| **结构单元** | 4课时 | 结构 | 设计鱼缸缸体与支架结构，分析受力特点；制作亚克力鱼缸或支架 |
| **流程单元** | 4课时 | 流程 | 设计鱼缸造景流程（清洗→铺设底砂→种植水草→注水），优化时序安排 |
| **系统单元** | 4课时 | 系统 | 设计鱼缸生态循环系统（过滤、增氧、温控），分析各子系统关联 |
| **控制单元** | 4-8课时 | 控制 | 设计智能温控系统、自动喂食器、远程监控，实现闭环控制 |

#### 单元评价

每个单元采用"作品评价+过程评价"的双重评价机制：

| 评价维度 | 评价内容 | 权重 |
|---------|---------|------|
| 作品评价 | 功能实现、外观工艺、创新性 | 50% |
| 过程评价 | 设计文档、试验记录、团队协作 | 50% |

#### 综合等级评价标准

| 等级 | 标准描述 |
|------|---------|
| 优秀 | 四个单元作品完整，功能达标；有创新设计；团队协作良好 |
| 良好 | 三个及以上单元作品完整，功能基本达标 |
| 合格 | 两个及以上单元作品完成，能体现核心概念应用 |
| 待改进 | 作品不完整或功能未达标，需重新提交 |

#### 设计意图

本案例以"生态鱼缸"为真实项目载体，用结构、流程、系统、控制四大核心概念贯通全部教学内容。通过16-20课时的完整项目实践，使学生深刻理解四大核心概念的内涵及其相互关联，实现核心素养的螺旋式提升。案例强调从真实问题出发，在"做中学、做中创"中培养工程思维和实践能力。
