# 教科研收件箱

临时放置尚未分类的链接、截图、想法、语音整理稿和文件说明。每周至少清理一次。

## 清理判断

- 能形成研究问题 → `30_研究资料/02_研究主题`
- 是文献、政策、同行案例或教研活动 → `30_研究资料` 对应分类
- 是现场采集的数据 → `40_真实数据`
- 是原始附件 → `60_原始资料`，并建立一条说明笔记
- 只是行动任务 → 写入相关研究项目
- 无价值或重复 → 删除或归档
