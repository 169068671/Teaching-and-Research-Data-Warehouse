# 待分解教科研材料

将待处理的文章、论文、课题资料、教案、课件、学习单、试卷、评价量规、实验任务书或课程资源包临时放在这里，完成 [[../../05_工作流/教科研材料数据化分解工作流]] 的阶段 0 和阶段 1 后，再把原件移动到 `60_原始资料` 对应分类。

## 提交材料时最好同时说明

- 希望解决的研究问题。
- 材料来源和是否允许长期保存。
- 是否包含学生或教师敏感信息。
- 期望只做审计，还是继续生成自己的研究设计。
- 是否需要处理全部附录、表格和图片。
- 如果是教学材料，是否还有课堂实录、学生作品、测试记录和教师反思可用于对照。

> [!warning]
> 不要把身份对应表、学生姓名、学号、联系方式等直接放入本仓库。
